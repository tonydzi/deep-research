# Deep Research — Palo Alto AI Research Lab

0 deep-research reports, distilled. Every entry answers two questions: why we ran this research, and what we got out of it.

Each report was run across several frontier models (ChatGPT, Gemini, Grok, Claude, GLM, Mistral), then reconciled into the distilled note you see here. Findings are the reconciled ones, not a single model's opinion.

Raw model transcripts stay in our vault. What is published here is the distilled layer: summary, key findings, recommendations, open questions.
