# DR26-07-05-HUB-05 — Синтез 3 вендоров

Вопрос сезона: **«Возьмут ли не-кодера с AI-кофаундером на работу в LLM-компанию?»** Два подвопроса: (A) как дать аудитории реально влиять на шоу без потери контроля; (B) как build-in-public конвертируется в найм в DevRel/community/dev-education в Anthropic/OpenAI-tier.

## ГЛАВНЫЙ ВЫВОД (все 3 сошлись)
**Реалити-шоу и цель №2 — одна машина, а не две.** Артефакты шоу (dev-log'и, лонгриды, метрики комьюнити, решения по голосованиям) — это ровно то портфолио, что скринят DevRel-хайринг-менеджеры. Правильный формат участия аудитории = «scoped consult/involve», НЕ «аудитория решает компанию». А статус «не-кодер с AI-кофаундером» — это не слабость, а **сильнейший маркетинговый актив**: он вживую демонстрирует ровно тот next-gen workflow (Claude Code / Cursor / vibecoding), который эти компании продают энтерпрайзу. «Ты — их идеальный будущий клиент, уже усиленный их моделями».

## Секция A — интерактив аудитории (консенсус)
- **Голосовать можно за последовательность и поверхностный UX; НЕЛЬЗЯ за ядро** (архитектура, безопасность, монетизация, цена, наём, точные деньги, приватные данные). Оба вендора дали почти одинаковую таблицу «votable vs founder-only».
- **Механика анти-захвата (Web3-параллель — DAO governance capture):** two-step (temperature-check опрос → потом биндинг на публичном роадмапе) + **timelock** (задержка между голосом и исполнением) + **veto-«стоп-кран»** с публичным объяснением технической причины + сразу 2 безопасные альтернативы на новый голос. Вето превращается в обучающий момент, а не в предательство доверия.
- **Масштаб решает механику:** <10k = качественно, «feedback as a feature», ответ <2ч, правило 70/30 (70% времени — на общение, 30% — на постинг), кредитить авторов идей. >10k = публичный роадмап + структурированные опросы по предвыбранным опциям + авто-уведомление «твоя фича → Shipped».
- **Этическая линия — жёстко на фабрикованной драме.** Аудитория = билдеры и хайринг-менеджеры, они мгновенно палят искусственный конфликт. Настоящая драма прикладного AI-инжиниринга (context-window, галлюцинации роя, latency) — сама по себе достаточно драматична. «Шрамы, не открытые раны».
- **Метрика резонанса:** bookmarks/saves > просмотры (просмотры — vanity).

## Секция B — конверсия в найм (консенсус + конкретика)
- **Shipping > дипломы.** Anthropic/OpenAI/Vercel/Supabase явно нанимают self-taught билдеров; публичные артефакты весят больше CS-диплома. (Confidence: **established**.)
- **Что реально скринят:** production-grade артефакты (не «обёртки над API», а сложная оркестрация — RAG-пайплайны, agent state, secure tool use), cookbooks/туториалы, GitHub с чистым обучающим кодом, community gravity (звёзды/Discord/X/конференции), «builder empathy».
- **Роли-2026:** Developer Advocate / Claude Relations (Anthropic, упор на MCP + steerable/safe), Developer Education Lead / Dev Marketing (OpenAI), Forward-Deployed / Product Engineer (Vercel AI SDK), AI DevRel (Supabase).
- **Interview loop:** screen (mission-fit, у Anthropic — жёстко на safety/steerability) → take-home (полноценная интеграция, ~20ч) → work-trial/live-demo перед скептичными инженерами → founder/exec round (system-design, high agency).
- **Документированные кейсы «публичный билд → найм»** (Gemini, самое ценное — прямые прецеденты):
  - **Peter Steinberger (OpenClaw → OpenAI)** — репо 9k→346k звёзд, публичный $1.3M токен-билл на 100 автономных инстансов; нанят вести «personal agents» за скорость и видение, ДАЖЕ с публично признанными дырами безопасности. (⚠️ для Антона это прямая параллель — openclaw-сайдкик уже в его контексте.)
  - **Alex Albert (Jailbreak Chat → Anthropic)** — публичные threads по jailbreak/интерпретируемости → первый resident prompt engineer → Head of Claude Relations.
  - **Logan Kilpatrick (Julia OSS → OpenAI → Google)** — комьюнити-адвокатство → возглавил DevRel.
  - **Rich Harris (Svelte → Vercel)**, **Delba de Oliveira (контент → Vercel)**, **Sandra Kublik (GPT-3 контент → Cohere)**, **Dennis (Bknd → Supabase)** — паттерн «beloved OSS/контент → компания покупает талант напрямую, мимо ATS».
- **Web3 → LLM переводится 1:1** (established): цель L1-фонда (девелоперы строят dApps → спрос на блокспейс) ≡ цель LLM-провайдера (девелоперы строят агентов → объём токенов). Словарь: «хакатоны» → «build-a-thons/AI pilots»; «retention билдеров» → «time-to-first-value/DX»; «governance/токеномика» → «AI safety/evals/system prompts»; «аудит смарт-контрактов» → «tool-use safety/MCP boundaries». ⚠️ Без Web3-максимализма и идеологии.
- **Путь и сроки (Gemini, конкретный план):** M1-2 строй+документируй публично (GitHub + 18-сек «doubter→proof» видео + cookbooks); M3-4 вживи их стек (MCP / Vercel AI SDK), найди дыры в их доках → опубликуй лучше; M5 инфильтрация сети (PR'ы, баг-репорты с репро, общение с их инженерами/DevRel на X/GitHub); M6 реферал → interview loop с живым портфолио. **Реалистично 4-6 мес** (Gemini) / **9-18 мес** (Grok, более консервативно) build→оффер. Оффер-цикл после захода: 1-3 мес.

## РАСХОЖДЕНИЯ (не сглаживаю)
1. **Сроки:** Gemini оптимист (4-6 мес), Grok консерватор (9-18 мес). Развилка: зависит от того, насколько «exceptional» артефакты и есть ли сеть. Бери Grok как базу, Gemini как upside.
2. **«Hire me» вслух:** оба говорят «помогает в builder-культуре, но рискует прозвучать как clout-chasing/mercenary для mission-driven компаний». Gemini жёстче предупреждает (Anthropic = «missionary не mercenary»; текущие клиенты Track A увидят flight-risk). Митигация: рамка «иду на фронтир технологии», а не «мне нужна эта работа»; агентство — decoupled, «инсайты апгрейдят то, что строю вам».
3. **Безопасность:** кейс Steinberger говорит «скорость победила дыры», но Gemini подчёркивает: 2026 год risk-averse к data-exfiltration автономными агентами → на дыры не закладываться. Скорость + видимая забота о безопасности.

## РЕКОМЕНДАЦИЯ (снайперский ответ на цель №2)
1. **Объяви вопрос сезона публично** — это и есть пилот (лежит в гейте 06). Превращает риск в нарратив.
2. **Смести формат с «показываю» на «строю ВМЕСТЕ»** — Participation Charter (votable/founder-only + two-step + timelock + veto) закреплённым постом.
3. **Строй на стеке целевых компаний** (Claude Code/MCP, Vercel AI SDK, Supabase) — каждый эпизод = одновременно контент И карьерный сигнал; агент-своарм-консенсус уже сейчас = ровно «production-grade оркестрация», которую скринят.
4. **Переупакуй Web3-трек** в DevRel-словарь (таблица выше) — это established-актив, не додумка.
5. **M5 сеть:** таргетно вживайся в доки/GitHub Anthropic/OpenAI, публикуй улучшения → реферал > ATS.
6. **Держи границы с Track A** (decoupled-нарратив) и НЕ фабрикуй драму.

**Следующий кирпич:** пилот сезона + Participation Charter → это первые 2 публичных артефакта, которые одновременно стартуют шоу и портфолио.
