# Insight (DR DR26-08-23-HUB-02-2226): Touch base — ледокол для спящего тёплого контакта

## Что закрыто

Стандинг-правило: **ритм = когда, конкретная дельта = гейт отправки**; пустое «давно не общались»
не отправляем никогда. Единственный легитимный ритуал без дельты — новогоднее сообщение (RU/CIS
окно), с одной реальной деталью, без просьбы, без повторной отправки при молчании.

Якорь по приоритету: невыполненный долг (только вместе с погашением) → их вопрос с готовым ответом →
их проблема + свежая дельта → публичная веха → вопрос-мнение к реальному эксперту → общий человек,
только если он и есть причина.

Звонок — не автоматическая конверсия. Для async-native (инженеры/мейнтейнеры/исследователи)
письменный артефакт/интро/ревью почти всегда лучше звонка, независимо от статуса контакта.
