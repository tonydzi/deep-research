# Insight (DR DR26-06-30-HUB-02): Шаблон промпта для генерации цепляющих твит-тизеров (хуков)

> Отчёт отвечает на вопрос, как составить промпт и методику для генерации цепляющих твит-тизеров, повышающих вовлечённость аудитории.

## Ключевые выводы
- Корректно составленный хук в первом твите повышает вовлечённость до 65%
- Лучший тизер сочетает психологические приёмы (любопытство, противоречие, эмоции, FOMO) с конкретикой и обещанием ценности
- Правило 4U — тизер должен быть Срочным, Уникальным, Полезным и Ультра-конкретным
- Ключевые техники: информационный разрыв/любопытство, противоречие/шок, конкретика с цифрами и списками, эмоциональные триггеры, прямое обращение на «ты»
- Готовый шаблон промпта задаёт роль «опытный копирайтер», лимит ≤280 символов, выбор одного приёма (любопытство/противоречие/польза/срочность/юмор/загадка) и требование не раскрывать всё сразу
- Составлено 10 примеров тизеров на русском для конкретного текста (про проект vs OpenAI, принципы «АК-47», масштабирование сообщества)
- Критерии оценки тизера: цепкость (hook), ясность/релевантность, ценность (promise), уникальность, краткость
- Предложен 10-дневный план A/B-теста: подготовка версий → запуск теста на подгруппах → сбор метрик (CTR, вовлечённость) → анализ → выбор победителя → верификация стабильности

## Рекомендации / решения
- Использовать приведённый шаблон промпта как стандартный для генерации твит-тизеров
- Оценивать каждый сгенерированный тизер по 5 критериям (цепкость, ясность, ценность, уникальность, краткость) перед публикацией
- Проводить A/B-тест из 2-3 вариантов тизера по описанному 10-дневному плану, а не выбирать вариант интуитивно
- Применять правило 4U и конкретные примеры приёмов (curiosity gap, FOMO, шок-статистика) как чек-лист при написании
