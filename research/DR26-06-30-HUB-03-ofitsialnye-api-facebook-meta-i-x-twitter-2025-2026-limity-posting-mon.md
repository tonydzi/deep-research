# Insight (DR DR26-06-30-HUB-03): Официальные API Facebook/Meta и X(Twitter) 2025-2026: лимиты, постинг, мониторинг, анти-бан

> Как легально и безопасно постить/читать личный профиль FB и аккаунт X через официальные API в 2025-2026, какие лимиты и цены действуют, и какие агрегаторы/фолбэки использовать.

## Ключевые выводы
- Meta Graph API нативно НЕ позволяет постить на личный профиль FB (publish_actions убран с 2018) — только на Pages и группы; чтение своих постов возможно через GET /me/posts с правом user_posts без App Review, если работаешь только со своими данными.
- Graph API лимиты: 200 вызовов/час на пользователя стандартно, до 4800/час для одобренных бизнес-приложений; отдельно считается X-Page-Usage для страниц.
- X/Twitter API v2 с 2026 — pay-per-use, бесплатного тира нет: чтение своих данных $0.001/ресурс, публикация $0.015 за твит без ссылки и $0.20 с любой ссылкой; legacy Basic ($200)/Pro ($5000) доступны только старым подписчикам.
- X ограничивает непроверенные аккаунты ~50 оригинальными твитами/сутки (ответы/ретвиты до 200); превышение лимита API (100 постов/15мин, 10000/сутки на приложение) даёт 429 и риск блокировки.
- Для личного профиля FB нет ни вебхуков, ни надёжных RSS-мостов — единственный устойчивый мониторинг: собственное приложение + user-token + опрос /me/posts каждые 5-10 минут; скрейпинг веб-страницы ненадёжен (капчи, блокировки).
- Безопасные лимиты постинга: FB — не чаще раза в 5-10 минут, 5-10 постов/сутки; X — держаться ~50 оригинальных твитов/сутки и не более 1 поста/минуту, с человеческим (не бот-) паттерном таймингов.
- Браузер-автоматизация (Playwright/Selenium/Claude-in-Chrome) — единственный вариант постинга в личный профиль FB (раз API не даёт), но она рискованна и требует имитации человека (User-Agent, случайные задержки, стабильная сессия); для X браузерный обход API прямо запрещён и ведёт к перманентному бану.
- Сравнение агрегаторов постинга FB+X: Postiz и Mixpost — open-source/self-hosted варианты; Buffer — бесплатный старт + доступное API; Ayrshare — дорогой, но богатый унифицированный API; Make.com и Zapier поддерживают FB Pages, но убрали интеграцию с X (2023/2025); Typefully/Hypefury заточены под X.
- Топ-3 риска: (1) блокировка за частоту постинга — решается щадящим графиком и случайными паузами; (2) отзыв прав приложения — решается официальным App Review и бизнес-верификацией Meta; (3) детект/капча при скрейпинге — решается человекоподобной автоматизацией и процедурой ручной разблокировки.

## Рекомендации / решения
- Для мониторинга личной стены FB использовать собственное Graph API приложение с user_posts правом и опросом /me/posts каждые 5-10 минут через n8n, уведомления слать в Telegram-бота — бесплатно и разрешено правилами.
- Для постинга в X использовать нативный X API v2 напрямую (HTTP/n8n), закладывая оплату по факту (несколько центов за пост), не обходить лимиты.
- Для постинга в личный профиль FB (раз API не даёт) — единственный путь Playwright или Claude-in-Chrome с человеческим поведением, запускать по расписанию через n8n, логиниться один раз и не перелогиниваться.
- Если нужен надёжный/платный вариант постинга сразу в FB Pages и X — брать Buffer Pro или Publer Business (официальная поддержка обоих каналов, минимальный риск бана), либо дорогой Ayrshare для максимума функций; но ни один из них не решает постинг в ЛИЧНЫЙ профиль FB.
- Держаться безопасных лимитов постинга (FB: раз в 5-10 мин, до 5-10 постов/сутки; X: ~50 оригинальных твитов/сутки, не чаще 1/мин) и человеческого паттерна активности, чтобы избежать блокировок.
- Пройти официальный App Review и бизнес-верификацию Meta заранее и хранить long-lived токены с обновлением, чтобы не потерять доступ приложения.

## Открытые вопросы
- Точный повышенный лимит оригинальных твитов/сутки для проверенных (Premium) аккаунтов X не раскрыт.
- Нет данных о существовании бесплатных специализированных сервисов мониторинга личной ленты FB.
- Неофициальные пороги (например, '1 пост в 6-10 минут для FB') основаны на жалобах пользователей, а не на официальной документации — точность не подтверждена.
