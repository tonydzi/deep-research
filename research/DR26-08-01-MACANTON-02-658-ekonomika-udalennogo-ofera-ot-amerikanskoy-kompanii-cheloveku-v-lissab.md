# Экономика офера из Лиссабона: что реально ляжет на счёт

> **Вердикт (обе рельсы сходятся): механика найма существует, но «американский payroll по US-вилке дистанционно из Лиссабона» — не дефолт и ни у одной frontier-лаборатории публично не подтверждён.** Реальная сделка = португальская занятость через EOR либо B2B-контракт, почти всегда без employee-equity. `[консенсус 2/2 рельс]`

## 1. Что подтверждено обеими рельсами

| Утверждение | codex/chatgpt | grok | статус |
|---|---|---|---|
| Anthropic / OpenAI / xAI / GDM / Meta нанимают по офисам либо заранее одобренным странам; Португалии в списках нет | ✅ | ✅ | **консенсус** |
| Hugging Face — самый remote-native из списка, реальная дверь для публичного OSS-профиля | ✅ | ✅ | **консенсус** |
| US-вилка не переносится: Perplexity прямым текстом пишет, что USD-range только для US, international — по локальному рынку | ✅ (цитата вакансии) | ✅ | **консенсус** |
| IFICI («NHR 2.0») при работе на американского работодателя через обычный EOR **обычно не квалифицирует** | ✅ | ✅ | **консенсус** |
| У контрактора нет автоматического права на equity/PPU; tender — редкое окно, не ликвидность | ✅ | ✅ | **консенсус** |
| Поездки на он-сайты: ESTA/B-1 покрывают митинги, оффсайты, конференции; «недели обычной работы в офисе» — красная зона | ✅ | ✅ | **консенсус** |

## 2. Цифры (порядок величины, не офферные данные)

Порог семьи из шести с четырьмя детьми в англоязычной international-школе:
- codex: **€115–165k net/год** (школа €50–90k + жизнь €60–75k)
- grok: **€130–200k+ net/год**
- перекрытие, которое можно использовать как рабочий порог: **≈€130–165k net**

Что этот порог закрывает (обычный IRS, без IFICI):
- **$150–200k gross — не закрывает** дорогую international-школу ×4.
- **$250k — пограничен** (contractor ≈€117k net, employee ≈€99k по расчёту codex).
- **$300k+ cash** либо **€200k+ при подтверждённом IFICI** — устойчиво закрывает.

⚠️ Крупный «TC», где $150–250k приходится на неликвидное частное equity, **не является деньгами на школу**.

## 3. Единственное расхождение рельс — и оно решающее

**Anthropic Fellows.** codex поставил их **№1** в лестнице промежуточных ступеней ($3,850/неделю, ~$65k за 4 месяца, высокая конверсия «внутри лаборатории»). grok поставил №3 и **флагнул то, чего codex не флагнул: Fellows — US/UK/Canada only, то есть из Лиссабона это не путь без временного переезда.**

Проверка: собственная же таблица codex говорит, что remote-friendly роли Anthropic ограничены «обычно США/Канада/Великобритания» — то есть grok прав, а codex не свёл своё же ограничение со своей же рекомендацией.

**Разрешение:** Fellows остаётся самой высокой конверсией в оффер, но это **релокационная ступень**, а не удалённая. В лестницу «платит сейчас, не сходя с места» она не входит.

## 4. Что это меняет в решении-потребителе

Потребитель: *«целимся в прямой офер, в EMEA-роль или в промежуточную оплачиваемую ступень»*.

1. **«Прямой офер от Anthropic/OpenAI/xAI с сохранением Лиссабона» — снять с доски как основной сценарий.** Не потому что «нас не возьмут», а потому что инструмент отсутствует: они нанимают там, где есть юрлицо. Держать как upside, не как план.
2. **EMEA-роль — не запасной вариант, а основной.** Hugging Face и AI-adjacent (LangChain, W&B, Modal, Replicate, Continue) — единственные, где remote-international из PT документирован. Целевые семейства ролей: Applied / AI Deployment / FDE / Solutions, Developer Experience **вместе с инженерией** (не чистый евангелизм), evals / safeguards / red-teaming.
3. **Промежуточная ступень, которая реально платит из Лиссабона сегодня** — экспертный контракт через Mercor / Surge / Handshake (Mercor: средняя $81/ч, senior-домены до $200/ч). Это кэш без релокации; конверсия в оффер средне-низкая, потому что лаборатория-заказчик обычно не раскрывается.
4. **Гранты (Sovereign Tech, NLnet, GitHub Accelerator/Sponsors, Alpha-Omega) — это runway мейнтейнера, а не hiring funnel.** Ни одна рельса не нашла подтверждённой конверсии грант → оффер. Не ставить их в план дохода семьи.
5. **Шесть пунктов, без которых «$300k оффер» экономически неопределён** (главный переговорный чек-лист): cash base · страна занятости · gross-vs-employer-cost · eligibility по equity · eligibility по tender · ожидания по поездкам.
6. **IFICI считать только upside** — после письменного заключения португальского налоговика и подтверждения компетентного органа. Бюджет строить по обычному IRS.

## 5. Три посылки брифа, которые исследование опровергло

1. «Эти компании routinely employ people who are not in the office» ≠ «можно жить в любой стране» — вакансии систематически различают Remote-US, country-specific remote и перечисленные офисы.
2. US-вилка автоматически не переносится в Лиссабон.
3. EOR — не нейтральная административная оболочка: он превращает офер в португальскую занятость (местный payroll, 23.75% employer SS) и может **сломать** квалификацию по IFICI.
