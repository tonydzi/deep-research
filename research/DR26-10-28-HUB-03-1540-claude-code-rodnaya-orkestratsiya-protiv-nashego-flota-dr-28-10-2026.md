# Claude Code: родная оркестрация против нашего флота (ДР 28.10.2026)

**Вопрос.** Что умеет родная оркестрация Claude Code в октябре 2026, куда идёт, где пересекается с нашей шиной, write lease, ролями и хуками, что брать. Заказ Антона 28.10 «иди на их гитхабы… контрибьютим… делай DR». Дельта к ДР 11.10 (рои) и решению 25.06 (Agent Teams только как opt-in для read-only).

## Что сошлось у всех четырёх ног
1. **Пять режимов параллельности:** subagents, agent view (research preview), agent teams (experimental, выключены по умолчанию), dynamic workflows (план в коде на JS: 16 агентов параллельно по умолчанию, до 256, потолок 1000 за прогон; цифры из ноги ChatGPT по доке workflows), projects (public beta, Pro/Max). Версия на 27.10: v2.1.312.
2. **Agent teams не изолируют тиммейтов в worktree.** Дока сама говорит «partition the work», два тиммейта на одном файле затирают друг друга. Единственный замок: на захват задачи, не на файл. **Per-file lease в Claude Code нет вообще.** Наш тезис из DR26-10-27-HUB-04-1451 подтверждён 4 из 4.
3. **Всё внутри Claude-only.** Воркеры только сессии Claude; Codex, Grok, Cursor входят лишь как MCP-инструменты. Мультивендорность и мультимашинность для разнородных агентов = не цель Anthropic (вывод, а не анонс).
4. **В anthropics/claude-code PR извне невозможны** («Only collaborators can create PRs»). Вклад = точное воспроизведение в issue. Плагины идут через форму в каталог, не PR.

## Расхождения (не усредняю)
- **Межмашинные сообщения.** ChatGPT, claude.ai и Mistral: у Claude Code уже есть `ListAgents`/`SendMessage` между сессиями на одной машине (сокет/именованный канал), на другой машине и в облаке; другая машина идёт через Remote Control и серверы Anthropic. Grok написал «межмашинного нет». **Grok пропустил фичу, тут он неправ** (3 против 1, у claude.ai цитата версии v2.1.224/225, у ChatGPT Windows с v2.1.234). Это самое сильное новое пересечение с нашей шиной.
- **Agent teams в долгую.** Grok и claude.ai: свежая статья Anthropic 22.10 «когда сворачивать субагентов в главный цикл» советует один цикл + навыки по требованию, команды остаются experimental. ChatGPT: курс на единый субстрат сессий и оркестрацию кодом. Оба вывода помечены вендорами как вывод.

## Что у них полезно нам (вердикт)
1. **Worktree на каждого пишущего Claude.** `--worktree` и `isolation: worktree` закрывают большую часть столкновений, против которых у нас lease. Lease оставляем для разнородных агентов и общей папки (наша рабочая папка даже не git).
2. **«Proposed, not done» кодом:** хук `TaskCompleted` с exit 2 отбивает «готово» без артефакта ревьюера; `TeammateIdle` так же. Наши роли сейчас держатся на тексте контракта, тут родная точка принуждения для Claude.
3. **Состояние ролей вне контекста:** `SessionStart` с matcher `compact` перевпрыскивает роль, lease и состав. Лечит потерю личности после компакта (issues #55586, #64550, #23620 по ноге claude.ai).
4. **Сообщение другого агента не даёт согласия.** У Anthropic межагентное сообщение не может одобрить действие и поменять конфиг. Берём правилом в шину для всех вендоров: это наш §0.14 машиной.
5. **Межсессионный `SendMessage` как третья рельса внутри узла** для пар Claude↔Claude (было в ДР 11.10 кандидатом, теперь подтверждено доками). Шину не заменяет: она мультивендорная.
6. **Общая полка навыков = открытый формат Agent Skills (SKILL.md).** Его читают Codex, Cursor, Gemini CLI. Наша полка уже на нём, подтверждение курса §9.3-тер.
7. **Dynamic workflows для Claude-only веера** (аудиты, миграции, ревью). Agent teams для пишущей работы не включать; решение 25.06 остаётся в силе.

**Что они делают, а мы нет:** дашборд всех сессий (`claude agents --json`). Кандидат скормить его выход в нашу шину вместо самописного обзора сессий Claude.
**Где мы впереди:** разнородные вендоры, 8 машин без сервера, per-file lease, тиры одобрения на весь флот. Клетка по-прежнему пустая у Anthropic.

## Побочная находка про нас
Наш `block_dangerous_bash.py` не ловит глоб-удаление в общей папке (`find … -name 'tmp*' -exec rm`, `rm -r dir/tmp*`). Класс «массовое удаление по маске» у нас оплачен (02.10 чистка AppData, 24.06 скиллы). Кандидат на починку, отдельной сессией.
