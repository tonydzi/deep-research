# Insight (DR DR26-10-09-HUB-03-2112): Lenses.io Community Edition — чем полезна лаборатории

> Вопрос Антона (09.10.2026): «чем нам может быть полезна эта тулза» (lenses.io/community-edition). Проверены пять дорожек: инфра (Kafka как «один лог» флота) · безопасность (MCP-сервер с OAuth 2.1) · OSS-вклад · найм · контент/демо.

## Вердикт одной строкой
Lenses CE полезна нам как **предмет разбора и образец дизайна**, а не как инфраструктура. (Счёт честно: заказано 6 рельс, доехали 4 вендора + вторая нога Gemini, ChatGPT и Mistral не доехали; «4/4» ниже = четыре собранных вендора, недоехавшие могли бы разойтись. Рецепт «один лог без брокера лечит дрейф» = гипотеза, замер назван в рекомендации 2, не факт. Панель ломателей 14.10 это и потребовала.) Ставить Kafka+Lenses на хаб как шину флота — нет. Разобрать их MCP-сервер с OAuth 2.1, вытащить паттерны в `agent-approval-gate`, опубликовать независимый разбор — да, и это первое. Найм: не Lenses (24–28 человек внутри Celonis), а Redpanda и Confluent/IBM, куда такой разбор и есть портфолио.

## Ключевые выводы
- **Премиса из моего первого веб-прохода была ложной:** Celonis купил Lenses.io **5 октября 2021**, а не в 2024 (Celonis press, SiliconANGLE 05.10.2021; три рельсы независимо). Factor House пишет «early 2022» [single-source, конкурент]. Lenses.io Ltd живёт как дочка: EULA на её имя, ~24–28 сотрудников (PitchBook/Built In), офисы London · New York · Athens/Amsterdam.
- **EULA Community Edition жёстче, чем слово «community»** (lenses.io/legals/eula, «Last update: August 2025», первоисточник): лицензия на **две среды**, запрет публиковать бенчмарки и анализ производительности (§4.2(i)), запрет derivative works и «functionally similar product», право прекратить «at any time and for any reason», условия меняются без уведомления, ответственность $100. Про телеметрию/phone-home ни слова [no source found]. → Публиковать можно **разбор дизайна**, нельзя — наши замеры RAM/латентности Lenses.
- **Ресурсы:** docs требуют ≥5 ГБ памяти Docker только под compose CE (Postgres + HQ + Agent + Kafka); Gemini-нога цитирует 8 ГБ/4 CPU на агент. На хабе это конкуренция с GPU-инференсом и 4–5 постоянных контейнеров там, где сейчас ноль. Альтернативы легче на порядок: NATS ~11 МБ RSS [старый источник], Redpanda ~349 МиБ + Console ~42 МиБ [low-authority], Kafbat UI / AKHQ — один Apache-2.0 контейнер без капов.
- **Наша боль не в брокере.** Дрейф 2146/2227 — симптом четырёх независимых счётчиков, а не отсутствия Kafka. Один брокер на Windows-хабе = единая точка отказа для Маков и VPS, которые бывают офлайн; им всё равно нужен локальный outbox, то есть снова файловая шина. Syncthing терпит разрывы по дизайну, брокер — нет. Собственный NATS-пилот (07.2026) не прижился, значит узкое место — дисциплина одного пути записи, а не технология. Лечение: **один append-only лог (JSONL/SQLite) с offset'ами на потребителя, остальные рельсы — проекции** (Kleppmann; ActiveGraph arXiv 2605.21997 делает то же без брокера).
- **MCP-сервер Lenses — хороший и разборный образец** (README lensesio/lenses-mcp, обновлён 07.09.2026; FastMCP 4, Apache-2.0): RFC 9728 discovery, RFC 8414 metadata, PKCE S256, Dynamic Client Registration, RFC 7662 introspection с TTL кэша 0 (отзыв действует на следующем вызове), OTel-спан на каждый `tools/call`, разрушающие операции остаются за кликом человека в UI («agents compose, humans commit»). **Дыры, названные самим README:** (a) три грубых скоупа read/write/delete и «scopes are not enforced globally» — read-only сессия держится только на нижележащем API; (b) HQ работает с `unauthenticatedIntrospection: true` — оракул валидности токенов для любого, кто дотянется; (c) в introspection нет `aud`, а токен клиента пробрасывается в Lenses API — против MCP-спеки 2025-11-25 («MUST validate audience», «MUST NOT pass through»); (d) жив запасной путь через статический API-ключ. Сравнение: Confluent `mcp-confluent` — OAuth только для части инструментов, остальное на статических ключах, телеметрия пока не `DO_NOT_TRACK=true`; Redpanda Agentic Data Plane (AI Gateway, 02.2026) — самый полный gateway; Kong — tap всех LLM/tool-вызовов в Kafka. Lenses — самый self-hosted и бесплатно-инспектируемый из них.
- **Что копировать в наши двери** (`agent-approval-gate`, `agent-leash`, `telegram-mcp-kit`): скоуп на границе инструмента — нет скоупа → инструмент не регистрируется вовсе; audience-bound короткие токены (RFC 8707 `resource`, проверка `aud`, без passthrough); явный «human-commit tier» (не как тулза); `traceparent` от вызывающего агента — это и есть недостающая трассировка из разбора LangChain 06.10.
- **OSS-поверхность lensesio тонкая:** lenses-mcp 28★ / 3 форка / 0 issues / 0 PR / нет CONTRIBUTING; `agentic-engineering-for-apache-kafka` MIT 61★ (Kafka-skills для агентов, «MCP-agnostic»); stream-reactor ~1.1k★, 86 issues, ~90 PR в основном Scala Steward, релизы мержатся из закрытой `lensesio-dev` → разработка внутри, публичные PR импортом; за 90 дней ни одного видимого мержа постороннего. Кандидаты (если один PR): docs/security-нота про audience+introspection или `require_scopes` на инструменты в lenses-mcp; Gemini предлагает тулзу timeline/audit. Это «вклад ради строки в резюме», не кампания.
- **Найм:** у Lenses страницы Developer Advocate / Support Engineer / Kafka SRE, открыты ли сейчас — [unverified]. Соседи живее: Redpanda ищет **Forward Deployed Engineers** под Agentic Data Plane (US West/East, EMEA-remote; в тексте вакансии «Anthropic FDE, OpenAI Deployed Engineer, Palantir FDSE» как плюс; UK base £131,914–£155,194; Gemini: $194–277K), Confluent (внутри IBM с 17.03.2026) — Streaming AI / Applied AI / WarpStream; Aiven, StreamNative, Conduktor, Materialize, RisingWave, Decodable — не проверены [no source found].
- **Контент:** вендорское «агент крутит Kafka через MCP» уже написано (Lenses 11.05.2026, Confluent MCP+Agent Skills GA, Kong «Agentic Commit Log» 17.06.2026, AutoMQ, Waehner 26.05.2025). **Prior art не найден** для независимого адверсариального разбора, как Lenses/Confluent/Redpanda на самом деле enforce'ят скоуп, audience и approval — с патчем в своём инструменте (claudeai искал по блогам/докам/MCP-auth-обзорам, не по Reddit/HN/X; Gemini и GLM тоже «not found»). Это наш свободный угол.
- **Ландшафт Kafka сдвинулся:** Kafka 4.0 (03.2025) только KRaft, share groups (KIP-932) production-ready к 03.2026, Diskless Topics (KIP-1150) приняты голосованием 02.03.2026, не GA. Kafka запускать одному стало проще, но нам это не нужно.
- **Бесплатные тиры умирают:** Lenses Box требовал перерегистрации каждые 6 мес; Conduktor пересобрал free-лицензию 02.2026 и закрыл Desktop; Provectus kafka-ui брошен → форк Kafbat. Прод-зависимость от бесплатного проприетарного UI — ошибка.

## Что добавила Grok-нога (CLI, платная рельса; 5 заметок по 35–52 КБ, страницы ОТКРЫТЫ, код запинен на git tree `efdad5b0…` master lensesio/lenses-mcp, 09.10.2026)
- **README врёт в минус себе:** приложение README говорит «scopes are not enforced globally… can be added», а в коде `config.py` функция `oauth_required_scopes()` возвращает FastMCP `require_scopes` **на каждом инструменте**, когда `OAUTH_ENABLED=true` (в CE включён по умолчанию; в голом репо по умолчанию `false` и тогда нужен статический `LENSES_API_KEY`). Это противоречит выводу claudeai-ноги (она читала README, не код). Беру Grok: он открыл файл.
- **Реальные дыры в дереве (цели для PR, issues открытых — 0):** (1) `execute_sql` помечен скоупом `read`, а демо вендора через него делает INSERT; (2) `verify_token` не сверяет `aud` с `MCP_ADVERTISED_URL`; (3) README-приложение противоречит коду; (4) `set_action_on_kafka_connector` отдаёт restart/start/stop как тулзы, хотя FAQ 11.05.2026 говорит «только через UI-подтверждение»; (5) скоуп `delete` упоминает топики, а в `topics.py` delete-тулзы нет; (6) `unauthenticatedIntrospection: true` обязателен по их же сниппету и противоречит RFC 7662 §2.1/§4; (7) нет allowlist топиков, dry-run и поля «агент-актор»; (8) `INTROSPECTION_CACHE_TTL=0` — правильный дефолт, не «улучшать». Хороший образец в коде: SHA-256 отпечаток токена вместо логирования bearer; жёсткий отказ вместо тихого фолбэка на общий ключ; `request_topic_creation` с письменной причиной, почему approve-кнопки нет (upstream-роут только под логином).
- **Чужие паттерны, которых у Lenses нет:** Confluent `read_only: true` отключает мутирующие тулзы через `readOnlyHint`; Redpanda вводит принципала `Agent::"<name>"` отдельно от пользователя и запрещает агентам выпускать креды/менять OAuth; Cursor — per-tool approval + allowlist + network deny по умолчанию.
- **OSS-поверхность цифрами:** 12 репо с пушем за ~90 дней; читаемый Python только lenses-mcp (0 issues) и skills-репо (1 слабый issue); `good first issue` в орге нет ни одного; единственный bounded docs-патч — stream-reactor #1589, 0 комментариев с 23.01.2025; однословный docs-PR там же лежит без ревью. CLA нет; skills-репо требует DCO + issue перед новым скиллом.
- **⭐ Найм — живая дверь у самой Lenses (индекс careers открыт 09.10.2026, 4 роли):** **«ML & AI Engineer»** (на странице «AI Engineer»), контракт, hybrid, Madrid/London/Munich с релокацией, hiring manager Guillaume Aymé, must-have: Python, PyTorch, Pydantic, **FastMCP, «Building agentic AI systems»**, обязанности: «agentic AI systems that utilise streaming data from Apache Kafka», MCP, Claude Code/Cursor/Codex; nice-to-have: «Producing educational content, e.g. blog posts, talks»; RSU, цифры нет; заявка на careers@lenses.io — https://lenses.io/careers/ai-engineer. Рядом **«Senior AI & Developer Experience Product Manager»** (Europe, FTE, тот же менеджер) — https://lenses.io/careers/senior-ai-product-manager. У Celonis 226 вакансий по их API, ни одной с Kafka/MCP/DevRel/FDE в названии; ближайшие по городам: Paris «Senior/Lead AI Deployment Engineer» (jobId 8007977003), New York «Lead Deployment Architect» (7796205003) и «Applied AI Engineer» (7765659003), London «Lead/Senior Solutions Architect» (7788552003, 7784638003). Это переворачивает «NO-GO найм в Lenses» трёх браузерных рельс: роль есть, и она буквально про наш стек. Уровень/контракт — не фильтр (§9.14).
- **Контент — три свободных угла, не «ещё один happy-path»:** (1) Windows/WSL2 и слом Box→6 API в 2026-гайде не описаны (ask.lenses.io 2024-12-16, 2025-03-03); (2) `unauthenticatedIntrospection: true` никем независимо не разобран против MCP-спеки; (3) никто не сравнил файловую шину агентов с NATS и Kafka и не сказал «Kafka — нет, Lenses MCP = admin-copilot, не шина». Практикующих обсуждений Lenses CE/MCP за 2025–2026 почти нет (вендорские блоги, тихий репо, один тред про Box→6).

## Рекомендации / решения
1. **Неделя 1 — «Governed MCP, audited» (дорожки 5+2, GO).** День 1: CE локально на хабе как лабораторный образец (Docker ≥6 ГБ, порты только на localhost, EULA принять; замеры не публиковать). День 3: то же против `mcp-confluent` (локальный Kafka) + доки Redpanda ADP → таблица: гранулярность скоупов · точка enforcement · audience · passthrough · human-commit tier · аудит · телеметрия по умолчанию.
