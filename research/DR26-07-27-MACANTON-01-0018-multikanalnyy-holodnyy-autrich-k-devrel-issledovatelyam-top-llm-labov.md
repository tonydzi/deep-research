# Insight (DR DR26-07-27-MACANTON-01-0018): Мультиканальный холодный аутрич к DevRel/исследователям топ-LLM-лабов: реальные reply-rate по каналам и последовательность

> Какая последовательность каналов (X/email/LinkedIn/GitHub/Discord/формальные программы) и какие сообщения дают наибольший шанс, что DevRel/исследователь в топ-AI-лабе заметит и ответит соло-билдеру без диплома/связей.

## Ключевые выводы
- Публичное проверяемое proof-of-work (воспроизводимый артефакт, замороженные логи+верификатор, смёрженные PR, закрывающие issue цели) + оффер вклада бьёт credentials/похвалу/job-ask; contribution-first письма DevRel-лидерам дали ~7.2% позитивных ответов (Skyp, Q1 2025, 3k писем, единичный источник)
- Формальные программы и GitHub выше по сигналу, чем холодные приватные каналы: Anthropic Claude Community Ambassadors (один набор ~90k заявок), OpenAI Codex Ambassadors (на паузе с середины 2026, форма интереса), Mistral ambassadors + прямой devrel@mistral.ai
- Мультиканальные последовательности дают 2-3x lift к reply-rate против одного канала (консенсус практиков + анализ алгоритмов 2026)
- X DM холодным: 5-12% при гиперперсонализации+Premium, часто <5% реально работает — большинство холодных DM падает в Message Requests, которую редко проверяют
- Cold email: 3.4-7.2% в среднем по tech, 6-15%+ при персонализации/сигнале; LinkedIn: accept 28-50%, reply 10-15% (хорошие кампании 15-25%), InMail 10-18%
- GitHub PR/issue-comment, закрывающий issue мейнтейнера — не измеряемый reply-rate, но высокий качественный сигнал замеченности (кейс: OpenAI нанял создателя OpenClaw после 175k-star GitHub-проекта)
- Рекомендованная последовательность на 1 цель: день −7..−3 публичный warm-up (реплаи/GitHub-комментарий) → день 0 PR закрывающий issue или заявка в формальную программу → день 2-4 публичный follow → день 5-7 приватный touch #1 (короткое сообщение, без ссылок, без job-ask) → день 10-12 другой канал → день 14-18 финальный touch или стоп; всего ≤3-4 приватных касания
- Жёсткие стопы: массовые/шаблонные рассылки, холодные DM staff в Discord без публичного вклада, лидирование с job-ask/питчем, игнор тишины и продолжение приватных касаний, таргет на человека, сменившего роль (пример: Alex Albert перешёл с Claude Relations/DevRel-adjacent на Research PM)
- Почти все количественные reply-rate — это proxy из B2B-продаж/рекрутинга; для конкретного случая (соло-технарь без продаж, ищущий заметности/найма у топ-лабов) прямых измерений почти нет

## Рекомендации / решения
- Вести аутрич через готовый публичный артефакт + оффер вклада, не через похвалу/резюме/job-ask
- Приоритет: формальные программы (Claude Ambassadors, Codex-for-OSS, Mistral ambassadors) и GitHub PR, закрывающие реальные issue, — прежде холодных приватных каналов
- Сперва публичный warm-up (ранний тематический реплай в первые 10-30 мин под свежим постом, или содержательный GitHub-комментарий), потом только приватное касание
- Сообщения — предельно короткие, конкретные, человеческим голосом, soft-ask/no-ask; в первом DM без ссылок, без «Loved your work!» и календарных ссылок
- На X DM не полагаться как на основной канал — Message Requests часто не открывают; не наращивать объём, останавливаться рано при тишине
- Соблюдать day-by-day каденцию (см. key_findings) со спейсингом 2-4 дня между приватными касаниями; ≤3-4 приватных touch на цель
- Перед КАЖДЫМ приватным касанием заново проверять, что цель всё ещё в той же роли (<5 минут: профиль, свежие посты, careers page) — роли двигаются часто
- Замерять открытия/ответы по каналу и итерировать только там, где есть сигнал; при негативном ответе — полный стоп по этому человеку

## Открытые вопросы
- Точные reply-rate именно для соло-технического билдера (не sales/recruiting), пишущего DevRel/исследователям топ-лабов — почти не измерены
- Реальный open/reply rate холодных DM именованным сотрудникам лабов не измерен
- Успешность холодных DM staff в Discord неизвестна
- Долгосрочная конверсия конкретных последовательностей в найм/оффер не прослежена
- Спор не разрешён: X DM даёт 8-25% (claim операторов-практиков) vs структурная реальность (Message Requests почти не видят) — нужен контролируемый эксперимент с open-rate трекингом
- Насколько инбоксы лабов уже перегружены AI-агентскими питчами после бума 2025 — неясно
