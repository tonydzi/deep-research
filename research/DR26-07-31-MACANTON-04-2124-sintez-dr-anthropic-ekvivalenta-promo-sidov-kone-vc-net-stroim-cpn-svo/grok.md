## Decision Memo (1 page)

**Decision:** Build the **Anthropic services-partner path** (CPN + cert + own lead magnet), **not** a clone of kone’s **promo-seat** OpenAI SMB motion. Mirror kone’s **offer structure** (sprint + adoption + LMS), swap ChatGPT→Claude Team/Code/agents.

**Why now (Jul 2026):**
- CPN + Services Track are **live and free** with published Select math.  
- Promo Claude seats for partners **not verified** → don't wait for them.  
- kone.vc proves **services margin + one free seat** works on OpenAI; seat is optional, sprint is the product.  
- Your OSS + agent fleet is stronger **social proof** for Anthropic DevRel/offer than a resale badge.

**Exact conditions / fences:**
1. Apply CPN this week; enroll Partner Academy; pass Foundations.  
2. Apply Ambassador if you will host ≥1 event / quarter.  
3. Ship **one** public customer story (pilot OK) within 90 days.  
4. Lead magnet = Readiness Map / OSS seed — **never** claim free Claude Team seats.  
5. Client contracts Anthropic; you don't resell seats.  
6. OpenAI SMB only if (a) dual GTM deliberate and (b) agreements don't kill Anthropic ambassador/partner narrative.

**What would flip the decision:**
- Anthropic publishes official **SMB channel + partner-distributable Team seats** → re-evaluate kone clone on Claude.  
- OpenAI SMB gives **documented** seat economics + easy entry **and** you choose OpenAI-first revenue → dual or pivot.  
- Select requirements relaxed for small AI-native firms → accelerate directory push.  
- Evidence that partner directory drives SMB pipeline (your Hub referral data after 2 quarters) → double down on co-sell; if zero inbound → invest in own FB/TG demand, treat CPN as credibility layer only.

**90-day DoD:**
- [ ] CPN Registered + ≥1 personal Claude cert  
- [ ] Ambassador applied / decided no with reason  
- [ ] Lead magnet live (form → report)  
- [ ] Offer page: Sprint + Retainer  
- [ ] ≥2 paying or published pilots  
- [ ] Path to Select: cert headcount plan + story #1  

**Confidence overall:** Program structure Anthropic **established**; OpenAI SMB economics **emerging**; conversion of audit/A2A **speculative** until you measure.
