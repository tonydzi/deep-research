## Одной строкой

Четыре независимые рельсы сошлись: **наш reply-rate 71–93% — это триаж, а не отношение**, и дальше растёт не число ответивших, а доля тех же 40 человек, кто вернулся ВТОРОЙ раз или сам принёс задачу. Публичных данных, переводящих reply-rate в вероятность оффера, не существует ни у одной рельсы.

## Что сказали все четверо (консенсус 4/4)

1. **Холодный PR без живого issue структурно мёртв** — не только у нас (замер ×2), но и по регламентам OpenAI Codex («по приглашению»), Gemini CLI (авто-закрытие), Qwen Code, UK AISI Inspect, Ghostty (бан). *established*
2. **Решающий шаг — не merge, а момент, когда мейнтейнер САМ инициирует следующий ход** (assignment, review-request, переход в приватный канал). *established*
3. **Second-touch** (тот же человек ответил повторно спустя ≥48 ч с новым содержанием) — единственная метрика, к которой пришли все четверо порознь. Исследований, что она предсказывает оффер, **нет ни одного**. *emerging*
4. **Горизонт — месяцы:** 3–9 (gemini), 1–5 в малом коммерческом OSS (chatgpt), «кварталы, не 2 месяца» (grok). Наши 2 месяца = ступень 2–3 из 6. *emerging*
5. **У крупных вендоров merge — не KPI.** Разговоры без мержей — физика, а не провал; «громкостью не чинится». *established*
6. **Риск-2026 — главный карьерный риск лаборатории с агентами.** curl закрыл bug bounty, Ghostty/tldraw/cryptography банят, GitHub выдал kill-switch. ⚠️ grok прямым текстом: профиль «2 инженера + агенты + 75 PR / 2 мес» снаружи читается как contribution farm — **даже при высоком качестве**. *established*
7. **Write-up НЕ повышает reply-rate того же мейнтейнера — данных нет** (4/4). Контент работает на третью аудиторию и как обязательный evidence-pack для заявок GDE/MVP/Ambassador. *нет данных / emerging*
8. **Формальные программы — реальные лифты, и почти все требуют номинации ИЗВНЕ:** MVP (самономинация невозможна), GDE (реферал Googler'а), Google Peer Bonus (номинирует сотрудник). Наши 40 ответивших = пул номинаторов.
9. **Числового порога спама GitHub не публикует** (4/4). Любые недельные потолки — наши fail-closed цифры, не отраслевая норма.

## Где рельсы разошлись

- **Потолок касаний расходится втрое:** chatgpt 8/нед, claudeai ≤2 на репо, grok 12–15, gemini по матрице ≈26. Никто не измерял — каждый выдумал. Взят самый тугой: цена ошибки асимметрична.
- **gemini даёт точные проценты там, где трое отказались** (25 строк на PR, +29–39% в понедельник, 66% мусора в curl, дата закрытия bounty). Не подтверждено вторым источником → 🤔. Зато только он принёс регламент `inspect_evals` с мая 2026 (arXiv-препринт + QA-логи + canary-строка) и правило MCP «Disclose it. Own it».
- **Дверь к Anthropic — четыре разных ответа.** Единственная численная планка во всём ДР — **Claude for Open Source: 100+ смерженных PR в чужие репо за 12 мес** (claudeai, одиночный источник) → 🤔 проверить у вендора до планирования. Сходятся на форме: дверь через MCP/cookbook-рельсу и качество потока, не через личность. Совпадает с нашим замером — bcherny отвечает штампами триажа.
- **Кейс «контрибьютор → найм во frontier-лабораторию» не задокументирован ни разу.** Чистый кейс есть только у HF (Niels Rogge, и тот подал формальную заявку); остальное — OSS-native продуктовые компании (Turso ~5 мес, Onyx, Vercel, Block). Для Anthropic/OpenAI/Qwen/vLLM — ноль публичных именных кейсов.

## Решение (Decision Memo, коротко)

**Опция B + программная полоса 10%:** потолок ≤8 новых касаний/нед на лабораторию, ≤2 PR/нед (все issue-anchored), ≤1 касание на человека в 7 дней, **0 холодных PR** как инвариант, ≥50% усилий — follow-up с теми, кто уже ответил. Стоп-кран: reply-rate новых ниток <60% → режем объём.

Потолки по вендорам, ритм недели (пн люди → вт диагностика → ср исполнение → чт переход отношений → пт измерение), пять возражений с ответами и таблица уверенности — в `SYNTHESIS.md`.

**Тень несёт обе даты (§5.7):** старт 25.08.2026 → 🌾 урожай **06.10.2026**. Критерий флипа объявлен заранее: 🟢 `STR30` вырос + ≥3 инициативы мейнтейнеров; 🔴 `STR30` и мержи упали при нуле инициатив.

**Первые три хода:** (1) четыре счётчика в `github_reply_meter.py` — `STR30`, `MIR30`, `invites`, `cold_pr`; (2) потолки записать машинно в конфиг `maintainer-weekly`, чтобы у правила была дверь, а не заметка; (3) self-nomination в PyTorch Contributor Awards — единственная найденная дверь без внешнего привратника.

## Чего рельсы не знают

Медианы «ответ → оффер» нет. Причинного исследования «каденс → reply-rate» нет. Эффект write-up на reply-rate не измерен. Порога спама GitHub нет. Разбивки merged-PR «внешние vs сотрудники» для `anthropics/claude-code` нет. Формальных community-программ DeepSeek не нашла ни одна рельса.
**Три рельсы из четырёх сказали прямым текстом: наш собственный датасет (94 треда / 30 дней, 40 ответивших, cold PR = 0 дважды) сильнее публичной литературы для этого вопроса.**

## Недобравшие рельсы (поимённо)

- **glm** — `chat.z.ai` анонимно принимает ввод, ответ не генерируется 40 с, тумблера поиска нет без логина. Причина = нет логина на узле.
- **mistral** — не залогинен на Mac, требуется принять ToS = Tier-2, без Антона не жму.
- **codex-дубль** — FAIL, 0 байт за 988 с; два нулевых артефакта в `results-failed/` — оборванные прогоны моста, payload доставался из tool-results.

🧒 Простыми словами: мы научились так, что нам ОТВЕЧАЮТ почти все — это здорово, но это как «привет» в дверях. Дружбы это ещё не значит. Дружба — когда тот же человек написал нам ВТОРОЙ раз сам. Поэтому теперь мы не рассылаем больше писем, а возвращаемся к тем сорока, кто уже ответил, и приносим каждому по одной полезной вещи. И перестаём стучаться в двери без приглашения — за это в этом году бьют по рукам.
