# OpenRouter — как использовать ПРЯМО СЕЙЧАС (июль 2026): синтез 3 вендоров

> Гетеро-консенсус ChatGPT (Pro, 45m/112 ссылок) + Gemini (Deep Research) + Grok (Heavy, 2m5s/478 источников). Все три — настоящие прогоны с поиском (гейт «0 searches → dead» пройден у всех). Расхождения НЕ сглажены — показаны как развилки. Канон DR-протокола: alpha-protocol-recall-plus-dr.

## 🎯 TL;DR — что делать с нашим свежим аккаунтом (все 3 согласны)
1. **Пополнить ≥$10 сразу** — это единственный рычаг, который поднимает free-лимит с **50 → 1000 запросов/день** (RPM остаётся 20). Без этого free-слой почти бесполезен для флота.
2. **Free-модели (`:free` / `openrouter/free`) — только фоновая грунт-работа**: разметка, дедуп, классификация, суммаризация логов. НЕ критический путь, НЕ устойчивый многоагентный поток (20 RPM бьёт быстро).
3. **Management Keys + Guardrails с первого дня**: пер-агентные ключи с жёстким дневным cap (напр. $5/день) + ZDR + opt-out тренировки. Это защита от runaway-циклов.
4. **BYOK наш OpenAI-ключ для эмбеддингов** — первые 1M запросов/мес бесплатно от комиссии OR, дальше 5%. Обходит 5.5% top-up fee.
5. **Приватность сразу**: opt-out тренировки + `zdr:true` / `data_collection:"deny"` для всего непубличного (иначе часть провайдеров, особенно free, логируют/тренируются).
6. **Fusion (`openrouter/fusion`) — только для дорогих задач** (ресёрч, критика, сложное планирование), НЕ рутина: это панель моделей + судья, цена = сумма всех вызовов (~4–5×), не бесплатный авто-роутер. Наш $0-прогон = внешняя модель НЕ подняла панель.

## ✅ Консенсус (совпало у всех троих — [established])

| Тема | Согласованный факт |
|---|---|
| **Fusion** | Параллельный fan-out на панель моделей (дефолт: Opus+GPT+Gemini Pro) → модель-судья синтезирует (консенсус/противоречия/слепые зоны). Цена = сумма панели + судья, флэт-тарифа НЕТ. Хорош для high-stakes reasoning; плох для JSON-экстракции/чат-ботов/рутины. Рекурсия в агент-цикле = взрыв стоимости. |
| **Free tier** | 20 RPM всегда; **50 RPD при <$10, 1000 RPD при ≥$10 lifetime credits**. Годен для async фоновых задач, не для критического пути. Список free-моделей ротируется. |
| **Экономика** | Токен-цены = **passthrough без наценки**, совпадают с прямыми (Opus 4.8 = $5/$25 за 1M). Комиссия = **5.5% на пополнение кредитов**. Эффективно ~+5.5%. Management Keys = программные ключи с бюджет-cap на агента. |
| **BYOK** | Да, можно вставить наш OpenAI-ключ. Первые **1M запросов/мес бесплатно**, дальше **5%** от каталожной цены. Инференс биллит апстрим-провайдер. Лимиты = апстрима (НЕ пул OR). ⚠️ Тихий fallback на кредиты OR, если не включить «Always use my keys». |
| **Интеграция** | **«Anthropic Skin»** — `ANTHROPIC_BASE_URL=https://openrouter.ai/api` + `ANTHROPIC_AUTH_TOKEN=<or-key>` + `<key-var>=""` (пустая строка ОБЯЗАТЕЛЬНА, иначе 401). Через тот же клиент зовём `openai/gpt-*` и `x-ai/grok-*` по строке модели — готовая second-opinion рельса без отдельных SDK. |
| **Features ranking** | Routing/Fallbacks + Management Keys/Guardrails = **высшая ценность**; Observability = средняя; Presets = низко-средняя; **Classifiers (Beta) = маркетинг/низко** для маленькой команды. |
| **Риски** | Аутэджи 17 и 19 фев 2026 (~35–40 мин, кэш-слой) + БД-аутэдж авг 2025. Series B **~$113M, май 2026**. Приватность: OR по дефолту не тренит, но апстрим-провайдеры варьируются → форсить ZDR через Guardrails. |

**Единая рекомендация направления:** OpenRouter = ценный **дешёвый/free рельс для грунта + мультивендорный second-opinion слой**, а НЕ чистое удешевление прямого Claude для тяжёлого объёма (для этого прямой Claude всё равно дешевле по лимитам).

## ⚠️ Развилки — где вендоры расходятся (решает Антон)

### Развилка №1 (главная): насколько глубоко пускать OR — сайдкар vs основной шлюз
- **Grok + ChatGPT (сходятся):** OpenRouter = **сайдкар**. Первичные агенты остаются на **ПРЯМОМ Claude**; OR берёт только грунт + second-opinion. Grok прямо: «не оптимально гнать первичный поток через OR, пока прямой Claude — король качества и лимитов». ChatGPT: «Option A — Claude-First + OpenRouter Sidecar; требовать измеренных доказательств прежде чем ставить первичный Claude-флот за OR».
- **Gemini (агрессивнее):** Option 2 «Fully Managed Gateway» (его РЕКОМЕНДАЦИЯ) — гнать **ВЕСЬ** трафик Claude/Grok/Codex через OR как первичный роутинг+fallback слой, отказаться от BYOK для инференса, принять 5.5% как «плату за конвергенцию».
- **Развилка для нас:** консервативный путь (2 из 3 голосов) = сайдкар, прямой Claude первичен. Смелый путь (Gemini) = OR как единый шлюз ради failover/унификации. Моя оценка: **сайдкар** ближе к нашим правилам (prefer-included-limits-before-paid-api — сначала подписка/прямые лимиты; ak47-simplicity — не усложнять; single-point-of-failure шлюза реален — 3 аутэджа за год).

### Развилка №2: латентность-оверхед
- **Gemini** уникально квантифицирует: маркетинг обещает 25–40мс, реально **100–150мс** в проде (независимые бенчи). Критично для стриминга/голоса, безразлично для async.
- Grok/ChatGPT не акцентируют. → Для нашего фонового грунта не важно; учесть, если когда-то погоним интерактив через OR.

### Развилка №3: $0.80 минимальная транзакционная комиссия
- **Gemini + ChatGPT:** есть **$0.80 минимум** на пополнение → $10 top-up = эффективно ~8%, не 5.5%. Пополнять крупнее, чтобы размыть.
- **Grok:** говорит просто «флэт 5.5%». → Практика: пополнять $50–100 за раз, не $10.

### Развилка №4: BYOK-порог бесплатности (Grok сам поймал противоречие)
- Docs = **1M запросов/мес** бесплатно; pricing page = **$25k инференса/мес** бесплатно. Grok пометил `[single-source variance]`. Gemini подтверждает 1M-requests. → Для нас релевантен request-порог (мы под ним).

### Развилка №5: уникальные детали (по одному вендору — [single-source])
- **Gemini:** Fusion self-pairing (Opus+Opus) = **+6.7% точности** на бенчах; Fast Mode через OR (`CLAUDE_CODE_SKIP_FAST_MODE_ORG_CHECK=1` + `/fast`); session-stickiness через `session_id` в metadata для prompt-cache (до −90% стоимости).
- **Grok:** Series B вёл **CapitalG (Alphabet)**, оценка **~$1.3B**; free Poolside Laguna может тренироваться на вводе; X-сигнал @alexatallah/@OpenRouter про free Laguna (21.07).
- **ChatGPT:** самый детальный по data-policy провайдеров (OpenAI API не тренит бизнес-данные по дефолту; per-provider policy snapshots).

## 📋 Decision Memo

**Проблема:** свежий OR-аккаунт, $0 кредитов — что с ним делать нашему Claude-флоту, чтобы получить пользу, не наступив на грабли.

**Что знаем:** консенсус выше. OR зрелый (Series B), token-passthrough, но зарабатывает на движении денег (5.5%) не на токенах.

**Варианты:**
- **A. Сайдкар (2/3 голосов, рекомендую).** Free-грунт + second-opinion через OR; первичные агенты на прямом Claude. Плюсы: дёшево, безопасно, не создаёт single-point-of-failure на критическом пути, соответствует нашим правилам. Минус: не унифицирует биллинг/failover.
- **B. Единый шлюз (Gemini).** Всё через OR. Плюсы: failover, унификация, доступ ко всему open-weight. Минусы: +5.5% постоянно, зависимость от аутэджей шлюза (3 за год), против prefer-included-limits-before-paid-api.
- **C. Пока ничего/минимум.** Только free-эксперимент, без интеграции. Минус: не проверим second-opinion рельсу.

**Рекомендация:** **Вариант A (сайдкар)**, уверенность **[established]** на механике / **[emerging]** на «стоит ли вообще при наших уже-сильных Codex+Grok рельсах». Главное допущение: у нас уже есть Codex и Grok second-opinion рельсы → ценность OR для нас в первую очередь = **бесплатный грунт-бак (1000 RPD)** и **единая точка к open-weight моделям**, а не ещё одно второе мнение. 

**Первый конкретный шаг (когда/если возьмём в работу):** пополнить $10 (задача `task_baa074f6` уже это делает) → включить ZDR+opt-out тренировки → создать 1 Management Key с $5/день cap → прогнать одну free-модель на реальной грунт-задаче (разметка/дедуп) и замерить качество vs наш Sonnet-грунт. Это ответит на главный вопрос: даёт ли free-бак OR что-то поверх нашего бесплатного Sonnet-бака.

**⚠️ Не-цель:** не ставить первичный Claude-флот за OR без измеренных доказательств (сходятся Grok+ChatGPT).
