C. Пять конкретных маршрутов

1. Открыть уже существующую папку и поговорить без правки кода. В Cursor это чат или агент в открытом окне проекта, модель остаётся выбранной, пока её не сменят. В десктопе ChatGPT есть развилка ChatGPT или Codex и режим Chat против Work, можно открыть папку. В OpenCode документация — про агента над рабочей директорией. Отдельного «просто поболтать, папку не трогать» не описано. Plan-агент ограничивает инструменты, но это всё ещё сессия проекта. Лишний шаг: убедиться, что разрешения на edit и bash стоят deny или ask, потому что по умолчанию OpenCode разрешает операции без вопроса.

2. Приложить скриншот. Дока v2 говорит: в десктопе или вебе кнопка Attach file, вставка или перетаскивание. Модель видит PNG, JPEG, GIF, WebP. PDF и прочий бинарник в запрос не входят, страницу PDF надо сначала сохранить картинкой. Выбор файлов в десктопе суммарно до 20 МиБ. Картинка ещё должна пройти лимит самого провайдера. Это документ v2. Что диалог 1.18.32 совпадает побайтно, не доказано. В релизах 1.x есть вложения и открытие файла во вложении в активном проекте. В десктопе ChatGPT image inputs заявлены отдельной страницей возможностей. В Cursor пикер модели и агент есть, отдельную спецификацию вложений в этом прогоне не открывал.

3. Сменить модель на дешёвую. OpenCode: `/connect`, затем `/models`. DeepSeek — ключ с platform.deepseek.com. GLM — ключ Z.AI или пункт Z.AI Coding Plan, в доке пример модели GLM-4.7. Тот же Go за $10 уже включает DeepSeek V4 Pro, V4 Flash и GLM-5.1–5.3, но с потолком долларов в месяц, не «безлимит». Cursor: пикер или Ctrl+/. Свой Grok списывается из пула Cursor. Чужой DeepSeek туда официальным BYOK не входит. Cline и VS Code BYOK как раз для ключа или OpenAI-совместимого endpoint. Подписка ChatGPT в этот пикер не вставляется.

4. Две задачи рядом и откат. Codex: новый тред Local или Worktree, вторая задача не пачкает текущие файлы. Cursor: Agents Window создаёт отдельный checkout, потом можно вернуть результат в основной workspace, на Windows есть свой setup-скрипт. OpenCode v2: `/undo` откатывает и реплику, и файлы сессии внутри одного git-каталога, игнорируемые файлы и файлы вне каталога не восстанавливает, команды оболочки не отменяются. Отдельной кнопки «новый worktree на задачу» в открытых доках OpenCode нет. Плагин opencode-worktree упомянут в индексе экосистемы, это не встроенная кнопка.

5. Разрешение, терминал, фон. Codex на Windows: под композером режим одобрения, песочница режет запись вне папки и сеть, полный доступ предупреждают как опасный. Терминал на выбор: PowerShell, cmd, Git Bash, WSL. Расписание живёт в приложении, машина должна быть включена. Cursor Automations — облачные агенты по cron или по событию GitHub, GitLab, Slack, Linear, Sentry, PagerDuty, webhook. Компьютер в облачной VM включён по умолчанию. OpenCode: в конфиге `edit` и `bash` ставятся в ask. Встроенные инструменты включают bash, webfetch, websearch, skill. Отдельного расписания и встроенного браузера в открытых доках нет. Почта ни у OpenCode, ни в списке триггеров Cursor Automations отдельной кнопкой не описана. Сценарий «утренний бриф по почте» на странице десктопа ChatGPT — рекламный сюжет, не спецификация разъёма.

E. Цены, без фальшивого сравнения токенов

Это разные кассы. Месяц подписки не равен миллиону токенов и не равен «150 сообщениям».

OpenCode как программа бесплатен. Платишь провайдеру. OpenCode Go — $10 в месяц, необязательно. Потолки на модели, не на программу. Примеры с их страницы: GLM-5.3-Flash до $60 в месяц внутри этого плана, DeepSeek V4 Pro до $15, DeepSeek V4 Flash до $30, Grok 4.7 и Grok 4.6 до $15, и цена растёт после 200K токенов контекста. У DeepSeek внутри Go есть peak и off-peak. Оценка «сколько запросов» на той же странице посчитана на вымышленных типичных размерах запроса. Это не бенчмарк качества. Zen — отдельный каталог проверенных моделей со своим ключом и биллингом. Полную английскую таблицу Zen в этом прогоне не открывал.

Cursor. Grok 4.7 standard: $2 / $6 / $0.50 cache read за 1M. Fast: $4 / $12 / $1. Длинный контекст больше 256K: удвоенный standard или утроенный fast, окно до 500K. Это списывается из пула моделей Cursor. Свой ключ на индивидуальном плане провайдер считает сам, пул Cursor не ест. На Teams и Enterprise сверх ключа остаётся Cursor Token Rate $0.25 за миллион входных, выходных и кэшированных токенов. Подписку ChatGPT Cursor не принимает. Конкретные окна «сколько сообщений в 5 часов» в индексе старой страницы pricing были, живую страницу целиком не перечитывал, числа сюда не копирую.

Devin Desktop, страница, которая открылась вместо моделей Windsurf. GLM-5.3 High: $1.40 вход, $0.26 cache, $4.40 выход за 1M. Бесплатно на этой странице назван только SWE-1.6. Это их прайс, не прайс api.deepseek.com и не прайс z.ai.

Сравнивать «$10 Go» с «подписка Cursor» или с «$2 за миллион Grok» нельзя. В одном случае потолок долларов на конкретную модель. В другом — пул подписки и отдельные токены. В третьем — счёт API без потолка, пока карта жива.

F. Трение переезда

Чаты Cursor и Codex в OpenCode не переносятся. Этого моста в открытых доках нет.

Навыки частично совпадают только на v2: OpenCode сам читает «внутренний путь лаборатории», `~/.agents/skills` и проектные копии. Правила Cursor и промпт Codex туда сами не становятся.

MCP надо описывать заново. Форма конфига другая.

Опасный дефолт. Пока не выставишь ask на edit и bash, агент OpenCode по их конфиг-доку не спрашивает. У Codex на Windows вопрос и песочница — штатный режим.

Claude Pro/Max. Страница Anthropic: OAuth подписки только для обычного Claude Code и родных приложений Anthropic. Третьим лицам нельзя предлагать вход Claude.ai и гонять запросы через Free, Pro или Max. Страница провайдеров OpenCode одновременно показывает пункт Claude Pro/Max и пишет, что плагины так делать нельзя и из поставки их убрали с версии 1.3.0. Рабочим путём считать ключ API, Bedrock или Vertex. Не кнопку подписки.

ChatGPT Plus/Pro в OpenCode их док описывает как официальный вход. Это утверждение OpenCode. Отдельную страницу правил OpenAI, которая это разрешает именно для OpenCode, не открывал. Для десктопа OpenAI рабочий вход в текущем quickstart — аккаунт ChatGPT, не ключ DeepSeek.

Grok в Cursor не равен SuperGrok в OpenCode. Первое входит в кассу Cursor. Второе — device-login xAI или ключ с console.x.ai. Фраза доки OpenCode: подходит любой план Grok или X Premium, в который входит доступ к Grok API. Проверять свой план, не предполагать его.

Конфиг 1.18 и v2 разный. Обновляться вслепую не надо.

Разрешает ли OpenAI сегодня вход ChatGPT Plus именно в OpenCode. Док OpenCode говорит да. Страницу запрета или разрешения OpenAI не открывал.

Принимает ли сегодняшний десктоп ChatGPT ключ API. Старый текст Codex app говорил да, с урезанными функциями. Текущий quickstart говорит только «войди в аккаунт ChatGPT».

Есть ли у OpenCode Desktop кнопка worktree, расписание, встроенный браузер и поиск по истории. В релизах есть поиск, вкладки, ревью и терминал. Отдельных страниц на уровне доки Codex нет. Отсутствие страницы не равно отсутствию кнопки.

Почта. Ни один открытый документ не даёт пошаговый разъём Gmail для OpenCode. У Cursor почта упомянута в сценарии бота, не в списке триггеров. У десктопа ChatGPT почта есть в рекламном сюжете дня.

Roo Code и Kilo Code. Отдельные актуальные доки не открывал. Kilo всплыл только как клиент OpenCode Go: починка заголовка сессии заявлена для CLI, не для расширения VS Code.

Windsurf как отдельное имя. Живой URL моделей открылся докой Devin Desktop. Старый текст Cascade не подтверждаю.

OpenWork. Три разных смысла имени. Ни один не сверен как зрелая замена Cursor на Windows.

Цены планов Cursor, ChatGPT Plus и Copilot в долларах за месяц. Токенные ставки открыты частично. Абонентские ценники целиком не перечитывал, поэтому не ставлю.
