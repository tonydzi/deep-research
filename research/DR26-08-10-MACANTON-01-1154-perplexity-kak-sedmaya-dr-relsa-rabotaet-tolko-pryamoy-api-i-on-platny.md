# Insight (DR26-08-10-MACANTON-01-1154): Perplexity — какая поверхность реально работает без человека

> **База: 4 рельсы из 6** (chatgpt 66.7KB · grok 34.6KB · claude.ai 25.5KB · glm 19.2KB). Кворум §9.1 (любые 4 из 6) достигнут — слово «консенсус» законно. Не ответили: gemini, mistral. Оригиналы и SYNTHESIS.md: `_machine-bus/_dr/queue/DR26-08-10-MACANTON-01-1154/`.

## 🔴 Главное

**Единственная программная поверхность Perplexity для безлюдного крона — прямой HTTP API** (Sonar). Для DR-отчёта брать `sonar-deep-research` через асинхронную подачу: `POST /v1/async/sonar` + опрос статуса (синхронный вызов не переживает длинный ресёрч). Согласие 4/4.

## ⚠️ Поправка к первому пересказу: «MCP не работает» — НЕВЕРНО

Первичный отчёт Антону сжал три разных вердикта в одно слово («остальные три не работают или запрещены»). Синтез говорит другое, и живой пользователь MCP у Антона в знакомых это подтвердил:

| Поверхность | Работает? | Годится нам как cron-DR-рельса? | Почему |
|---|---|---|---|
| **HTTP API** (Sonar, `sonar-deep-research`) | ✅ да | ✅ **да, единственная** | async submit+poll, закреплённый model id, воспроизводимо |
| **MCP** (`perplexityai/modelcontextprotocol`, официальный) | ✅ **да, официальный и живой** | ⛔ нет | жрёт ТОТ ЖЕ платный API-ключ (подписку не тратит) · добавляет host-timeout и lifecycle процесса · `perplexity_research` дёргает изменяемый Agent-preset, а не нативный Sonar DR |
| **CLI** (`pplx`, официальный) | ✅ **да** | ⛔ нет | отдаёт Search API + извлечение контента, а НЕ готовый DR-отчёт; DR-shaped CLI пришлось бы писать самим поверх того же HTTP API |
| **headless / Comet** | ⛔ нет | ⛔ нет | нет поддерживаемого API автоматизации, CAPTCHA + гниение сессии + DOM-churn + бан, против ToS |

**Рекомендация синтеза дословно:** «MCP оставить для интерактивных сессий, официальный CLI только для raw search, web/Comet не автоматизировать». То есть MCP — нормальный инструмент для человека в чате; забракован он только в роли безлюдной рельсы.

## 💰 Денежный блокер (согласие 4/4)

Подписки Pro / Max / Enterprise **НЕ являются бюджетом Sonar API** — это отдельный pay-as-you-go счётчик. Значит Perplexity не проходит §6.3 «жечь оплаченное» без нового платного решения = **Tier-2, решает Антон**.

Цены Sonar: вход $2/M · выход $8/M · цитаты $2/M · reasoning $3/M · поиск $5/1000. Официальный пример прогона ≈ **$0.816**.
Оценки «5 отчётов в день» разошлись по рельсам и КАЖДАЯ single-source: $48/мес (glm) · $75–230 (claude.ai) · $75–300 (grok) · $105–338 (chatgpt). Брать как порядок величины, не как смету.

## 📉 Качество: цитаты ≠ синтез

Профиль смешанный — сильная привязка к источникам не даёт лучшего синтеза.
- ResearcherBench coverage **0.480** против 0.703 (OpenAI) и 0.693 (Gemini) — только claude.ai, не подтверждено.
- HLE **21.1%** против 26.6% (OpenAI) — только grok, не подтверждено.

## 🤔 Что осталось непроверенным (не цитировать как факт)

- Утверждение, что MCP-инструмент `perplexity_research` ездит на пресете `openai/gpt-5.6-sol` — **single-source (chatgpt)**. Именно оно сильнее всего бьёт по MCP как независимой рельсе, и именно оно не подтверждено.
- GLM в одиночку заявил, что async API не существует (отвергнуто большинством) и что есть жёсткий потолок вывода 10000 токенов (отвергнуто: официальный пример grok показывает 11395 токенов выхода).

## ✅ Вердикт для нашей системы

1. Рельсы MCP / CLI / headless **не строить**.
2. Если Антон разрешает новые деньги — маленький пилот ТОЛЬКО на API (`sonar-deep-research`, async) с жёстким потолком трат.
3. Если правило «жжём только оплаченное» держим — **отказаться целиком**, остаться на шести рельсах.
