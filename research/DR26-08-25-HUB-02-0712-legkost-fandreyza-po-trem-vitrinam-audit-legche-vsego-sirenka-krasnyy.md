## Вердикт (обе рельсы сошлись независимо)

**Ранжирование по лёгкости рейза для нашего профиля (команда без pedigree):**

1. **Аудит AI-агентов / MCP** — ВЫСОКАЯ фандабельность, $3-5M (stretch $6-8M). Якорь: CodeIntegrity $4.8-5M seed 27.05.2026, безымянная пятёрка, на offensive research. Наш актив (30 CVE + 21k инстансов + OSS-ответы) — единственный, что уже ПЕРЕШЁЛ границу нашей системы: третьи стороны могут проверить.
2. **Второй мозг / Сиренка B2B** — СРЕДНЯЯ, только как узкий клин, $2-3M (grok: $1-2.5M). Красный океан ЭКСТРЕМАЛЬНЫЙ: Glean $7.2B/$300M ARR, Dust 3000 орг ($40M Series B), Sana продан Workday $1.1B. Горизонтальное «поверх любых источников» уже занято. Фандабельно ТОЛЬКО как telegram-native knowledge/ops layer для messaging-first организаций. Корпус 1.47M сообщений сам по себе — слабый суррогат (нужны внешние платящие + retention + ROI).
3. **Оркестрация флота** — НИЗКАЯ сейчас (средняя после внешних deployments), $1.5-2.5M (grok: $0.5-1.5M). Категория переименовалась: деньги идут в production runtime / observability / permissions / audit, НЕ в «консенсус нашего флота». Внутренний флот без внешних jobs рынок не принимает. Нижний комп = Trace $3M (2 фаундера, но 550 ВНЕШНИХ workflows).

## ⭐ Три вывода, которые меняют решение

1. **Наш инстинкт был перевёрнут.** Сиренка/второй мозг, которую тянуло сделать рейз-продуктом, — САМЫЙ красный океан. Флот, которым гордимся, — слабейший предмет в одиночку. А сильнейшее — комбо.
2. **Рабочее комбо = аудит + флот, НЕ второй мозг.** Формула: «deterministic runtime security & resilience layer for autonomous agent fleets across machines/tools/MCP/A2A». Витрина 1 = продукт и владелец бюджета (security team); витрина 3 = стенд/доказательство/исполнение политики. Тащить витрину 2 в тот же питч = распыление (три покупателя, три бюджета).
3. **Поправка в наш питч (обе рельсы):** «self-healing БЕЗ human approvals» — баг. Enterprise покупает НЕ отсутствие контроля, а «без РУЧНОГО approval ВНУТРИ policy» + логи + rollback. Переформулировать везде.
