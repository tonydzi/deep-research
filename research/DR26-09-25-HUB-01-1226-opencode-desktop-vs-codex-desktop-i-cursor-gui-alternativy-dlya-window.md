# Insight (DR DR26-09-25-HUB-01-1226): OpenCode Desktop vs Codex Desktop и Cursor: GUI-альтернативы для Windows с доступом к DeepSeek/GLM

> Исследование сравнивает OpenCode Desktop с Cursor, Codex Desktop (ChatGPT desktop) и другими GUI-альтернативами по UX и доступу к дешёвым моделям (DeepSeek/GLM) для Windows-пользователя, не любящего CLI.

## Ключевые выводы
- Вердикт рельсы grok (основа этой заметки): «Не заменяй Cursor и десктоп Codex одним OpenCode Desktop. Оставь Cursor редактором... Оставь десктоп OpenAI для параллельных тредов, песочницы, браузера и расписания. OpenCode Desktop 1.18.32 держи боковой рельсой на тот день, когда задача должна идти в ключ DeepSeek или GLM».
- Версия — OpenCode Desktop **1.18.32**, стабильный тег, релиз от 21 сентября 2026; отдельно существует линия OpenCode v2 (бинарники подписаны 2.0.6) с другой схемой конфига (`providers` вместо `provider`) — это preview-линия, не апдейт боевого 1.18.32, и её фичи (вложения, undo-снимки) на 1.18.32 не доказаны.
- Касса OpenCode: платишь провайдеру (ключ DeepSeek/Z.AI-GLM/xAI и др.) или через OpenCode Go за $10/мес с потолками на модель (пример: GLM-5.3-Flash до $60/мес, DeepSeek V4 Pro до $15, DeepSeek V4 Flash до $30, Grok 4.7/4.6 до $15). Подписка Claude Pro/Max как рабочий вход в OpenCode официально не считается — Anthropic это запрещает.
- «Codex Desktop» как отдельного продукта не существует — это ChatGPT desktop с режимом Codex (Microsoft Store id `9PLM9XGG6VKS`, winget). Вход — аккаунт ChatGPT; ключ OpenAI API работает только для CLI/IDE-расширения, часть функций десктопа на ключе не доказана.
- Cursor: своя подписка + модели Grok 4.7/4.6/4.5 (сделаны вместе с xAI), BYOK есть только для OpenAI/Anthropic/Google/Azure/Bedrock — DeepSeek и GLM в списке BYOK нет. У Cursor есть Agents Window, облачные агенты, worktree на Windows, MCP, расписания по cron/событиям (GitHub/GitLab/Slack/Linear/Sentry/PagerDuty) — то, чего у OpenCode 1.18.32 нет вообще (ни встроенного браузера, ни расписания, ни готовой кнопки worktree).
- «Grove» в документации Cursor не найден вообще — есть только модели Grok 4.5/4.6/4.7 самого Cursor; это похоже на оговорку, но подтверждения нет (гипотеза, не факт).
- Пять маршрутов сравнения (папка без правки кода / вложение скриншота / смена модели на дешёвую / две задачи параллельно с откатом / разрешения и фон) показывают: у OpenCode по умолчанию действия разрешены без вопроса (нужно вручную ставить `edit`/`bash` в ask), а кнопки worktree и расписания в открытых доках нет.
- Короткий список (D) вендора: (1) оставить пару Cursor + ChatGPT/Codex desktop, дешёвую модель добавить только на побочную задачу; (2) VS Code + BYOK или панель Cline, если нужен дешёвый ключ внутри привычного редактора; (3) OpenCode Desktop 1.18.32 — если задача именно «агент над папкой + дешёвый ключ», с оговоркой про доки-через-команды и разрешения по умолчанию; (4) OpenCode v2.0.6 — только копией рядом, не замена боевой версии.

## Расхождение рельс
Первая версия заметки была построена практически на одном отчёте — **glm.md** (26K) — и рекомендовала OpenCode Desktop как основной вариант. Живой отчёт **grok.md** (36K, полный прогон с открытыми страницами вендоров и таблицей доказательств) даёт противоположный вердикт: не заменять Cursor/Codex Desktop, OpenCode — боковая рельса. Расхождение называется явно: где решение опиралось на glm.md, а не на grok.md — это и есть дефект синтеза, который правит эта заметка.

## Рекомендации / решения
- Не переносить рабочий процесс на OpenCode Desktop целиком — держать его сбоку для задач, которые нужно прогнать через DeepSeek/GLM/OpenCode Go.
- Оставить Cursor как основной редактор (там уже есть Grok через подписку) и ChatGPT/Codex desktop для параллельных тредов, песочницы и расписаний.
- Дешёвую модель внутри привычного окна пробовать через VS Code + BYOK или расширение Cline, если не хочется ставить отдельное приложение.
- Тестировать OpenCode v2.0.6 отдельной копией, не апгрейдом 1.18.32 — конфиг несовместим (`provider` → `providers`).
- Перед любым переездом — 30-минутный ручной прогон одного и того же запроса в Cursor и в OpenCode с тестовым ключом DeepSeek, без покупок и без секретов в конфиге.

## Открытые вопросы
- Стабильность OpenCode Desktop 1.18.32 как бета-продукта в постоянной работе не проверена руками (grok.md: «ни один продукт в этом прогоне не запускался»).
- Что именно из фич OpenCode v2 доки уже работает в 1.18.32 — не доказано.
- Полная английская таблица Zen (каталог проверенных моделей OpenCode) не открывалась в этом прогоне.
- Cursor Automations как канал для «почта/бриф» не подтверждён — это рекламный сюжет ChatGPT desktop, не спецификация коннектора.
