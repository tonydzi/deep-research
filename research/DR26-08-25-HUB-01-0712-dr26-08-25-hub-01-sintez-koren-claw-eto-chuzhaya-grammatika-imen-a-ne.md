# CLAW — занятая грамматика, не свободное слово

**Заказ:** Антон 25.08 — «в экосистеме openclaw/claude много вещей называющихся CLAW,
проведи ДР, интересно чем занимаются все эти проекты».

**Кворум:** 1 валидная рельса из 6. `chatgpt` — 57 уникальных URL, первичные источники
(GitHub API, патентные ведомства Австрии и Британии, официальные блоги). `grok` отклонён:
сам объявил «no-live-retrieval contract», 0 уникальных URL — ответ из памяти модели
(тот же тик, что отбраковал gemini в DR26-08-05-ZB-03). ⚠️ Вывод med-high и одновендорный;
grok независимо сошёлся по этимологии и составу кластера, но подтверждением не считается
(false-corroboration-two-sources-agreeing).

## Что оказалось: не коллизия, а НАЗВАННАЯ ГРАММАТИКА

В экосистеме сложился шаблон имени **`[префикс размера/материала] + Claw`**, и он забит
крупными игроками:

| Проект | Чем занят | ★ (25.08) |
|---|---|---|
| openclaw/openclaw | персональный агент-«лобстер», мессенджеры как интерфейс | 387 499 |
| ultraworkers/claw-code | Rust CLI-агент (каламбур от Claude, не форк OpenClaw) | 195 112 |
| zeroclaw-labs/zeroclaw | Rust-рантайм одним бинарником | ~32 600 |
| nanocoai/nanoclaw | лёгкая альтернатива OpenClaw на контейнерах | ~30 600 |
| sipeed/picoclaw | Go-ассистент для слабого железа | ~29 900 |
| **NVIDIA/NemoClaw** | эталонный стек запуска OpenClaw в OpenShell | ~22 300 |
| **nearai/ironclaw** | security-first агент-ОС на Rust | ~12 600 |
| openclaw/clawhub | официальный реестр скиллов | ~9 300 |

Дальше по убыванию: nullclaw, mimiclaw (ESP32), TinyAGI (бывш. TinyClaw), zeptoclaw
(эскалация приставок nano→pico→zepto), clawwork, X-OmniClaw (OPPO), goclaw ×2 разных,
десяток независимых ClaudeClaw, npm `@opsyhq/claw`, PyPI `clawagents`.

**Этимология доказана:** OpenClaw = бывший **Clawdbot** = «Claude + bot» с крабьим
каламбуром; Anthropic юридически попросила уйти от «Clawd» → Moltbot → OpenClaw
(официальный блог 29.01.2026). То есть CLAW — это не наше независимое слово,
а осколок имени «Claude», от которого чужой проект уводили по требованию юристов.

## Цена для нас

- **Находимость:** по запросам «claw agents / claw protocol / CLAW AI» первый
  семантический приоритет уходит OpenClaw. Маленькая лаборатория тонет.
- **Восприятие:** инженер, встретив `claw-consensus` без контекста, прочтёт одно из трёх —
  инфраструктура OpenClaw, форк-сателлит OpenClaw, или Claude-тематическая обвязка.
  Именно то, чего мы не хотим: наш протокол консенсуса — самостоятельная работа.
- **Езда на волне не работает:** прецеденты (yt-dlp, VSCodium) выигрывают, когда продукт
  реально форк/замена. OpenTF→OpenTofu, React Query→TanStack, Minetest→Luanti —
  все ушли из чужого пространства и выиграли; заимствованное имя становится
  «потолком объёма» и вечной сноской «это как X».
- **Заражение:** CVE-2026-27001 в OpenClaw (инъекция через рабочую директорию, high).
  Крупный инцидент автономных агентов пачкает публично ВСЕ «claw»-бренды сразу.

## Вывод и что делать

Вчерашняя рекомендация (24.08, «CLAW наш собственный корень») **опровергнута замером**:
я мерил только `claw+claude` и не увидел грамматику `[префикс]+Claw`. Честная поправка.

Три варианта, решение Антона:
1. **Оставить CLAW** — дёшево сегодня, но постоянная сноска «нет, мы не про OpenClaw».
2. **Обязательный составной токен** (`claw1024` как родительский бренд, голое CLAW не
   используем + явная строка «независимы от OpenClaw и Anthropic») — компромисс отчёта.
3. **Уйти из корня** на неологизм без коллизии — то же, что рекомендовал прошлый
   нейминг-ДР, и то, что сделали OpenTofu/Luanti.

Свободные кандидаты (замер 25.08, GitHub 0 репо + свободен юзернейм + свободен .ai):
`quorix1024`, `kvorum1024`, `konsen9`, `vekton8`, `harmo9`, `tessel9`, а также `claw1024`.

⛔ Юридическая чистота ни одного из них НЕ проверена: нужен knockout-поиск в
UK/EU/US поверенным до коммерческого запуска. Это не юридическая консультация.
