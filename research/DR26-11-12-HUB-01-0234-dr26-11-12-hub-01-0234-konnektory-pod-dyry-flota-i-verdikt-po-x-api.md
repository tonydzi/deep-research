## Вердикт по X official API (для H76340)

**Оставить официальную дверь, браузерную полосу X не расширять.**
1. 402 «credits depleted» = закончились кредиты, а не сломалась дверь. Страница цен прямо описывает лечение: авто-пополнение (не чаще 1 раза в 5 мин, не работает при нуле и минусе) + лимит трат на цикл. Включение авто-пополнения = привязка карты и трата, **Tier-2, решает Антон**.
2. 102 запаркованные браузерные попытки: разпарковывать в API, а не в браузер. X 14.02.2026 предупредил о приостановке аккаунтов за автоматизацию без человека (claude.ai, Mistral). Сам текст предупреждения в синтезе не сверен.
3. 🤔 Ответы: claude.ai и Mistral независимо пишут, что с 23.02.2026 программный «холодный» ответ блокируется (403). Ответ проходит, только если автор упомянул или процитировал нас. На странице цен это косвенно подтверждает отдельная ставка `summoned`. Первоисточник правила **не открыт**. До проверки строить ответы только на упоминаниях.
4. Дешёвое чтение: упоминания брать через `/2/users/{id}/mentions` как Owned Read ($0.001), а не поиском.
