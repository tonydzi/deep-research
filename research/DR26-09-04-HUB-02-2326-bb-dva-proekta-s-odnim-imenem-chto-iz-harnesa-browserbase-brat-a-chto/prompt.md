# Deep Research: bb (Browserbase internal agent) — разбор харнеса и применимость к нашему флоту Claude Code

## Что исследуем

`bb` — внутренний AI-агент компании Browserbase (https://getbb.app/), автор — инженер Browserbase **Derek Meegan**. Заявленные свойства (источник — эпизод подкаста, https://open.spotify.com/episode/7Ab7GaiPRXcYblR7XWh35T):

1. **Автономные операции**: первый ответ в саппорте, закрытие feature-requests с минимальным участием человека.
2. **Эффективность**: ручные воркфлоу (лог-дайвинг, дебаг) сворачиваются в одно сообщение в Slack или автоматический pull request.
3. **Code Mode Sandbox**: код исполняется в изолированной среде, которая никогда не касается сырых секретов и не раскрывает их.
4. **Just-in-Time Credentials**: креды выдаются динамически через integration proxy, а не лежат в статическом конфиге.
5. **Least-Privilege Tools**: права и доступ к инструментам вычисляются заново для КАЖДОГО отдельного вызова и каждой event-driven траектории.

Нужен фактический разбор: что из этого документировано и подтверждаемо, что маркетинг, и что из архитектуры переносимо к нам.

## Кто спрашивает (контекст — обязателен для ответа «полезно ли ИМЕННО нам»)

Мульти-машинный флот из 6 узлов (Windows-хаб с 2 GPU, несколько ноутбуков Win/Mac, Linux-анкер VPS), на каждом крутится Claude Code + Codex + Grok + Gemini как рабочие рельсы. Характер работ:

- **Кодинг и починка инфраструктуры**: python-скрипты, хуки, MCP-серверы, SQLite-базы, scheduled-tasks. Правка на одной машине обязана раскатываться на все.
- **Автономные рутины**: сотни запланированных задач; агент поднимает фоновые сессии сам, работает ночью без человека.
- **Исходящее наружу**: GitHub PR и issue-треды, посты, DM лидам, ответы в мессенджерах — от лица владельца.
- **Секреты сейчас лежат В ОТКРЫТОМ ВИДЕ** в файловом сторе (credentials.md плюс .env/.json рядом), синкаются между машинами Syncthing-ом. Агент сам логинится в сервисы, сам подставляет пароли в формы браузера.
- **Апрувы**: человек — узкое место; действия класса «деньги / необратимое удаление / секреты третьим лицам / юридические обязательства» требуют его подтверждения, остальное агент делает сам.

### Наши реальные болевые точки (замеры, не гипотезы)

- **187 невыполненных межмашинных задач** на одном узле, старшей 20 суток; 71 гниёт дольше недели.
- **142 непринятых deploy-посылок** по флоту, старейшая ждёт 32 дня; ещё 284 числятся применёнными БЕЗ машинного доказательства.
- **Апрув-окна вешают безлюдные сессии**: 93 из 101 блока апрува — вызовы планировщика из рутинной сессии; три зависшие сессии остановили спавн на 6 часов 42 минуты.
- **Тихо-зелёные приборы**: сторожа рапортуют успех, когда работа не приземлилась (243 включённых задачи против 41 строки в реестре выходов — выход заявлен у 17%).
- **Секреты в plaintext** на 6 машинах, синхронизируемых по сети.
- **Тесты, которые никогда не краснели**: ломатель сломал ядро 16 способами, регресс-сетка поймала 5.
