# Deep Research: агентское секюрити 2024-2026 — полная карта игроков и раундов в деталях

## Контекст (кто спрашивает)
Мы — маленькая AI-лаборатория, готовим pre-seed/seed рейз с клином «безопасность и control plane для флотов AI-агентов» (аудит агентов и MCP-серверов → runtime-диспетчерская: kill-switch, бюджеты, журнал действий, гейты одобрений). Нужна ПОЛНАЯ конкурентная карта категории с деньгами, чтобы (а) построить слайд «карта рынка + почему мы», (б) понять, какие суб-ниши уже заняты и где пусто, (в) знать, какие фонды дают чеки в эту категорию.

## Вопросы (по блокам)

### Блок 1. Карта компаний — по одной строке НЕ достаточно, нужны детали
Все стартапы категории «AI agent security / agentic AI security / MCP security / AI runtime security / AI-SPM». По каждому: название · год основания · фаундеры и их бэкграунд (Unit 8200? big-tech security? исследователи?) · что именно защищают (prompt injection, runtime guardrails, identity/IAM для агентов, MCP-специфика, governance/control plane, observability, red-teaming/audit, posture management) · стадия · ВСЕ раунды (дата, сумма, лид и участники, оценка если известна) · названные клиенты/design-партнёры · размер команды.
Проверить как минимум: CodeIntegrity, Runlayer, Trace, Noma Security, Aim Security, Lasso Security, Prompt Security, Zenity, Apex Security, HiddenLayer, Protect AI, Lakera, Robust Intelligence, Pillar Security, Knostic, Straiker, WitnessAI, Operant AI, Invariant Labs, Pomerium, AgentOps-класс — плюс всё новое за 2026, чего в этом списке нет.

### Блок 2. Деньги категории
Сколько всего венчурных денег зашло в agent-security по годам 2024/2025/2026 (данные Crunchbase/PitchBook/пресса). Крупнейшие раунды. Все M&A: кто кого купил и за сколько (Protect AI → Palo Alto Networks? Robust Intelligence → Cisco? Prompt Security → SentinelOne? Aim Security → ?), и что скупка значит для новых игроков.

### Блок 3. Сегментация: где тесно, где пусто
Разложить категорию на суб-ниши и по каждой: сколько игроков, сколько денег, стадия зрелости. Отдельно выделить: (a) безопасность ОДНОГО агента/модели vs (b) безопасность ФЛОТА взаимодействующих агентов (multi-agent, A2A, оркестрация) — есть ли вообще игроки в (b), кто ближе всех к «control plane / диспетчерская для флота агентов с kill-switch, бюджетами и журналом».

### Блок 4. Наш клин на этой карте
Кто ближе всех к нашему позиционированию (аудит агентских флотов + runtime control plane), чем они профинансированы, чего у них НЕТ (наша дифференциация: живой мульти-машинный флот в проде у самих, OSS-first, память/knowledge-слой рядом). Честно: где нас раздавят и какое позиционирование избегает лобового столкновения.

### Блок 5. Карта инвесторов
Фонды, которые системно инвестируют в эту категорию: cyber-спецы (YL Ventures, Cyberstarts, Team8, Merlin Ventures, Ballistic, NightDragon), генералисты с тезисами (a16z, Insight, CRV, Index, YC). Их публичные тезисы/посты про agent security 2025-2026. Кто из них пишет чеки pre-seed/seed командам БЕЗ security-pedigree (не-израильским, не ex-Unit-8200) — примеры таких сделок.

### Блок 6. Вердикт
Есть ли место для no-name команды с OSS-first GTM и работающим собственным флотом? Какие 5 proof-points инвесторы этой категории требуют на seed (клиенты? CVE-кредиты? design-партнёры? benchmark?). Какое позиционирование даёт максимальную конверсию в «да».

## Формат ответа
Сверху вердикт одной страницей (место есть/нет + где именно + 5 proof-points), затем большая таблица компаний с раундами (Блок 1), затем остальные блоки. Каждая сумма раунда — с источником и датой публикации. Нет данных — прямо «не раскрыто».
