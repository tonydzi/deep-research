# Вывод в одну строку

Три из четырёх ног независимо говорят одно: **верифицированного случая «меньше 100 звёзд и меньше 500 в неделю, потом 10 000+» нет ни одного**. Пакеты, которые дошли до 10k, ехали на чужой дистрибуции (документация других продуктов, официальный SDK, плагин-поток Claude Code, компания за спиной). Для нас реалистичная веха на 30 дней: **1 000 «настоящих» (без зеркал, без CI) в неделю, а не 10 000**.

# Где разошлись, и по какому критерию каждая нога судила

1. **Числа Gemini опровергнуты тремя другими ногами по первичным API.** Gemini пишет basic-memory «~134 000 в неделю, перегиб июнь-июль 2025», graphiti-core «~377 000», cognee «~21 500». Grok и Mistral вытащили pypistats `without_mirrors` напрямую: basic-memory 5 154 → пик 19 659 (19 302 у Mistral по другой границе недели) → сейчас 7 671; graphiti-core пик 402 230, сейчас 197 676. У basic-memory 134 000 нет ни в одном API. Gemini судит по нарративу и вторичным обзорам (ChatForest, OpenGauntlet), остальные по API. **Таблицу кейсов Gemini в решение не берём.** Единственное её использование: идея «Agent Skills / репозиторий навыков», сверенная с Mistral (плагины Claude Code у basic-memory).
2. **Заявленная неделя 10k у basic-memory** отличается между ногами: Grok 2026-04-20 (10 227), Mistral 2026-06-08 (первый 10k+, 19 302). Окна и границы недели разные (у Grok первый бакет 5 дней). Устойчиво: 5k → 10k+ внутри окна pypistats (с 2026-04-08), пик 19.3k–19.7k, откат к 7.7k.
3. **mcp-remote**: Grok дал базу 337 в неделю 2025-03-17 и 11 228 в неделю 2025-05-05; Mistral дал «~1 290 в неделю 2025-04-14» и ту же неделю 10k. Совпадает неделя перехода, база согласуется по порядку (337 → 1 290 → 1 958 → 11 228).
4. **Причина роста mcp-remote.** Grok: README с одной строкой для Claude Desktop, Cursor, Windsurf, дата-совпадения нет. Mistral: строка из доков DeepWiki MCP. Обе причины «чужие доки», ни одна не привязана по метке времени.
5. **Всплески не-роста.** Только Mistral и Grok заметили синхронный всплеск недели 2026-08-03/08-24 на graphiti-core, mcp-server-fetch, mcpo, cognee и смену счёта PyPI 2026-08-24 (перестал логировать не-wheel/sdist). Grok: до и после 2026-08-24 счётчики не сопоставимы. Это важно для нас: **наши 113 лежат уже в новом режиме счёта**.
6. **Планы по критерию.** Claude: сперва измерить, потом реестр, установка одной командой, один демо-пост, Obsidian-аудитория. Grok: сперва строка, которую чужая документация уже просит вставить; один запрос в официальный MCP Registry и не больше; ничего из «не делать». Mistral: реестр + server.json + 3 каталога, блоки установки по клиентам, один Show HN (лотерея за 6 ч), заимствованная дистрибуция (Obsidian, шаблон агент-фреймворка, плагин Claude Code), честное сравнение. Gemini: реестр, репозиторий навыков, бенчмарк в README, автопубликация Smithery/Glama, Show HN.

# Прямое опровержение внутри веера

- Gemini «basic-memory ~134 000/нед., июнь-июль 2025» опровергнуто Grok и Mistral (pypistats API, `mirrors=false`, 7 671 сейчас, пик ~19.3-19.7k). Gemini также обещает «>10 000 по прокси через 40k звёзд» для lightrag-hku: звёзды не загрузки.
- Gemini ставит Show HN в пятёрку «дешёвых ходов». Mistral меряет: Basic Memory 4 очка, cognee 6 и 9, LightRAG 1, и только mem0 (201) и Graphiti (142) попали, оба с командой. «Один Show HN» остаётся лотерейным билетом, не планом.

# Сводный порядок для sgm 0.4 (то, что стоит у ≥2 ног, кроме опровергнутого)

Нумерация моя, источники в скобках. Часы это оценки ног, не замеры.

1. **Измерение до всего (2-3 ч).** Считать только `without_mirrors` из pypistats, шум-коридор 50-200 в неделю, два соседних понедельника подряд, прежде чем радоваться. Живая база сейчас ~28 в неделю (claudeai) или в коридоре 50-200 (grok). Зафиксировать, что счёт сменился 2026-08-24. (claudeai, grok, mistral)
2. **Строка установки одной командой на клиент (3-20 ч).** `uvx sgm-mcp` / `claude mcp add` / блок для Cursor и VS Code в README и в релизных заметках. Это единственный механизм, который у mcp-remote дал 337 → 11 228 за 7 недель. Перенос на память-пакет неочевиден: mcp-remote был мостом, нужным каждому удалённому серверу. (grok, mistral, claudeai)
3. **Один запрос в официальный MCP Registry + server.json (2-4 ч), без массовых каталогов в том же месяце.** Прироста установок от листинга нигде не измерено (grok, claudeai); Mistral закладывает 100 → 300-800 как свою оценку, замера нет. Остальные каталоги (Glama, Smithery, PulseMCP, awesome-lists) только после чтения результата 30 дней. (все)
4. **Заимствованная дистрибуция, 1-2 попытки (8-16 ч каждая).** Obsidian-ориентированные гайды по агентам и памяти (вики-ссылки как уникальный крючок), шаблон или cookbook агент-фреймворка, листинг плагина/навыков Claude Code (паттерн basic-memory). Единственная категория, у которой есть проверенные кейсы выхода за 10k. (mistral, claudeai, gemini)
5. **Один демо-пост + один Show HN, один билет (6 ч).** Угол «агент помнит через ваши заметки и ваши вики-ссылки, без графовой БД и сервера», не «вышел 0.3.0». Не пересдавать. (mistral, claudeai)

# Что делать по kill-критериям (30 дней, `without_mirrors`)

- После шага 3: меньше 300 в неделю при живом реестре и трёх каталогах → проблема в позиционировании или имени, а не в дистрибуции (mistral). Правило остановки у Grok: если единственная новая поверхность это строка в реестре и число всё ещё 50-200, следующие каталоги не подавать.
- После шага 4: две настоящие попытки без упоминания в чужой доке за 30 дней → стоп-аутрич, строить интеграцию (плагин Obsidian или пакет навыков) и повторить один раз (mistral).
- После шага 5: не вышли на первую страницу HN или 50+ апвоутов в Reddit с первой попытки → не пересдавать.
