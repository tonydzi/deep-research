- developers.buffer.com MCP: `create_post` (shareNow/addToQueue/customScheduled), метрики `get_aggregated_post_metrics`; **инструментов ответов/комментариев нет**; лимиты по плану в окнах 15 мин/24 ч/30 дней.

## Расхождения ног (не усредняю)
1. **Buffer Free или Essentials.** ChatGPT и claude.ai: Free ($0) хватает, 750 create укладываются в 1000 запросов/канал/мес, если звать API детерминированно (не LLM-обходом очереди). Mistral и GLM: Free впритык и хрупко, брать Essentials $6. Мой вывод: стартовать на Free, перейти на $6 при первом 429.
2. **Мониторинг.** claude.ai, Mistral: главная статья расходов, а X всё равно не даёт программно отвечать/цитировать чужих (холодные ответы = 403 с 23.02.2026; цитаты/лайки/фолловы для self-serve убраны с 20.04.2026, по claude.ai и Mistral). Значит мониторинг полезен только как сигнал для ручных действий. twitterapi.io дешевле в ~30 раз, все ноги: серая зона, только чтение, не для публикации.
3. **Цена ответа в своём треде:** $0.010 (summoned) или $0.015 — проверить по консоли одним ответом.
4. **Typefully:** Creator $99/год, 1000 постов/мес (ChatGPT, Mistral); inbox/ответов через API нет. Запасной вариант, если Buffer откажет.
5. **Отброшены всеми:** Ayrshare (BYO с 31.03.2026, от $149), bundle.social (X cap 15/сут + сквозная плата X), Upload-Post (X cap 10/сут), Postiz/Blotato/OpenTweet ($29, дороже без выгоды), браузерные/cookie-сервисы (прямое нарушение правил X).
