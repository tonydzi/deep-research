## Главное простыми словами

1. **Публикуй один раз наверху, зеркала скопируют сами.** Официальный реестр MCP (registry.modelcontextprotocol.io) бесплатный, без ручного ревью, публикация командой `mcp-publisher publish`. С него сами берут Glama, mcp.directory, реестр GitHub (после разового ручного онбординга) и PulseMCP, когда откроется. 4 из 4 ног + Codex. Проверено: sqlite-graph-memory 0.3.9 там уже стоит, Glama отдаёт карточку (HTTP 200).
2. **Листинг в каталоге почти не приносит пользователей.** Независимый замер DataForSEO (27.10.2026): только 3 из 21 MCP-каталога получают больше 10 тыс. поисковых визитов в месяц, самый крупный (MCP Market) около 81 тыс. Полевой опыт MentionAgent: подали сервер в 30 мест, реально появился в 3. Разработчик на DEV Community: 6 каталогов, три недели, «ноль событий, которые можно приписать каталогу». Каталоги дают ссылки и SEO, а не установки.
3. **У скиллов закон концентрации.** Vercel (skills.sh, проверено на первоисточнике): 1 млн скиллов, ~280 млн установок за 7 месяцев, 375 скиллов (0,04%) дали 62% установок, почти половину скиллов поставили ровно один раз. Карточка без движения (пост, тред, рассказ) невидима.
4. **skills.sh нельзя «подать»: он показывает скилл только после установок.** `tonydzi/join-the-fleet` на skills.sh сейчас 404, а `second-brain-starter-kit` уже есть (200). Значит, витрина появляется от людей, которые ставят `npx skills add`, а не от формы.
5. **Деньги каталогов: четыре модели.**
   - Платная «быстрая полоса» и значки: mcp.so $39 разово (без ревью, значок, dofollow-ссылка) плюс реклама $399, $699, $1 299 в месяц; mcpservers.org $39 (ревью за 24 ч вместо двух недель); MCP Market $29 и $69 против бесплатной очереди 4-6 недель. По сути это SEO-бизнес, продающий ссылки.
   - Хостинг и шлюз оплачивают бесплатный каталог: Glama (платные тарифы шлюза и хостинга MCP).
   - Захват платформы: Anthropic, OpenAI, GitHub, Docker, Cursor, Vercel держат свои каталоги ради собственного продукта. Arcade (раунд $60M летом 2026, данные из вторичных источников) купил Smithery 05.08.2026 и 31.10.2026 выключил её прокси, аккаунты, CLI и SDK; каталог остался витриной.
   - Корпоративные закрытые реестры и правила допуска: GitHub даёт компаниям свой реестр и белый список для Copilot/VS Code, PulseMCP продаёт реестр для организаций.
   Выручку ни один каталог не публикует (все 4 ноги: UNKNOWN).
6. **Живые витрины с настоящими пользователями сидят внутри продуктов.** Каталог Claude (портал claude.ai/directory/manage, открыт всем на платном плане с 25.09.2026), каталог плагинов ChatGPT/Codex, Cursor Marketplace, Docker MCP Catalog, Cline. Входы самые строгие (валидация `claude plugin validate`, политика приватности, пометки инструментов, тестовый аккаунт, ручное ревью), зато Anthropic даёт автору аналитику установок по поверхностям. PR в `anthropics/claude-plugins-official` больше не смотрят.
7. **Awesome-листы закрываются от массовых и роботных подач.** awesome-claude-code: рекомендацию подаёт только человек через форму, по одной, нужно ≥100 звёзд или 14 дней жизни (проверено по CONTRIBUTING). awesome-claude-skills: автозакрытие ниже 10 звёзд, запрет PR, написанных ИИ, 891 открытый PR. punkpeye/awesome-mcp-servers: робот CI требует бейдж оценки Glama, агентам разрешено, если пометить PR 🤖🤖🤖.
8. **Каталоги замусорены.** GLM: из 10 716 удалённых точек в официальном реестре около четверти не работают; Mistral: 32,8% серверов без коммитов 180+ дней. Наше преимущество: проверка установки на чистой машине и живой бейдж здоровья.

## Что это значит для трёх рутин «Раздай миру» (task-2026-11-17-razday-miru-catalogs-design)

1. **Тулзы: автоматическая публикация в официальный реестр MCP из CI** (GitHub Actions с OIDC на каждый релиз PyPI/npm) для каждого нашего MCP-сервера. Один раз настроить, дальше зеркала забирают сами. Это заменяет большую часть ручных подач по сайтам. Плюс Glama claim + бейдж (открывает awesome-mcp-servers) и Docker MCP Catalog для локальных серверов вроде sqlite-graph-memory.
2. **Скиллы: тематические плагины в одном нашем marketplace-репо**, установка и через `claude plugin install`, и через `npx skills add`. Не 232 поштучно. В портал Claude и в каталог OpenAI (путь «skills only») 1-3 лучших пакета, руками Антона (платный план, ревью неделями).
3. **Каталоги-сайты = дешёвые ссылки, не канал.** Платные полосы не берём: $39 × 55 репо = $2 145 за значки без доказанных установок. Бесплатные формы (mcpservers.org) по 10 минут, без спешки.
4. **Главный рычаг не каталог, а движение.** Раз 0,04% скиллов собирают 62% установок, рутина раздачи должна в связке с `share-fix-daily` и контентом приводить людей к установке: тред, пост, ответ в issue со ссылкой на `npx skills add`.
5. **Прибор `give-metrics` меряет воронку, а не листинги:** показ → клик → установка → первая успешная операция → повтор → звезда. Источники: скачивания PyPI/npm, счётчик skills.sh, рефереры и клоны GitHub, аналитика портала Anthropic. Карточка в каталоге без установок = 0.
6. **Правила дверей в поля `give-discover`:** «только человек», порог звёзд, бейдж Glama, запрет ИИ-PR, пометка 🤖🤖🤖. Нарушение правил листа ведёт к бану, а не к паузе.
