# Корпоративный второй мозг, 02.09.2026

Потребитель: решение про возражение «корпоратам нет смысла продавать второй мозг» + упаковка предложения.
Связано: insight-DR-DR26-08-26-HUB-01-0727-smb-market-penetration, insight-DR-DR26-08-25-HUB-02-0712-fundraise-ease-three-storefronts, decision-DR26-08-25-HUB-03-control-plane-raise-memo, two-storefronts-raise-and-acquihire, second-brain-northstar, false-corroboration-two-sources-agreeing.

## 🎙 Вердикт (три рельсы независимо, одинаково)

**Возражение «корпоратам нет смысла покупать второй мозг» — ОПРОВЕРГНУТО по сути, верно только как замечание про СЛОВО и упаковку.**

- Слово «second brain» = потребительский термин (Tiago Forte, PKM, Obsidian-культура). Строки бюджета с таким именем в энтерпрайзе НЕТ — тут собеседник прав. [established, 3/3]
- Сама работа — общий слой знаний компании, который читают люди и агенты — покупается за большие деньги под другими именами: enterprise search, knowledge layer, agent grounding, organizational memory. Доказательства деньгами: Glean $300M ARR / $7.2B (май–авг 2026) · ServiceNow купил Moveworks за ~$2.85B (март 2025) · Workday купил Sana за $1.1B (закрыто ноя 2025) · Capacity $100M ARR + купил Starmind (март 2026). [established, 3/3]

## Почему корпораты «не покупали» 30 лет (все три сошлись)

1. **Нет владельца бюджета.** Знания — проблема всех и P&L никого; CKO как титул вымер в 2000-х. Это сильнейший стилмен возражения: не «не нужно», а «некому подписать».
2. **Вклад = неоплачиваемый труд библиотекаря.** Люди не заполняют вики; SharePoint-кладбища и wiki rot — дефолтное состояние (McDermott 1999, Alavi/Leidner 2001).
3. **Одна уверенная ложь = потеря доверия навсегда** (Air Canada chatbot, BCCRT 2024).
4. Флагманский провал: **Microsoft Viva Topics закрыт 22.02.2025** — даже Microsoft не смог продать автоматический слой знаний отдельным SKU ($4/юзер против $30 у Copilot); работу спрятали в Copilot.

## Что изменили LLM и агенты

- **Read-side заработал:** RAG по существующему выхлопу (почта/чаты/тикеты/доки) снял проблему «людей-заполняльщиков». Контакт-центр 14% продуктивности (Brynjolfsson QJE 2025) — самый чистый независимый замер.
- **Write-side всё ещё падает** у людей — но **у агентов писатель = машина**, и это снимает 30-летнюю проблему вклада (если есть провенанс и срок годности, иначе «Viva Topics на скорости»).
- **Агенты сделали слой знаний ЖЁСТКОЙ зависимостью:** ~95% энтерпрайз-пилотов AI падают на данных/контексте, не на модели; Menlo: enterprise genAI spend 2025 = $37B, из них agents лишь $0.75B — узкое место контекст. Последовательность покупки: сперва Copilot/автоматизация → разочарование → докупают слой знаний, «чтобы купленное заработало». Второй мозг = апселл/подложка, не первая покупка.

## Новая категория — наша форма (Shape 4)

«Общее пространство знаний + агенты, которые его читают И пишут» — валидирована деньгами, доминанта нет, окно ~18–24 мес:
- **Interloom** (Мюнхен, март 2026, $16.5M seed; Zurich Insurance, Fiege) — «enterprise memory for AI agents», Context Graph. Ближайший к нам, на ~6 мес впереди по позиционированию.
- **Cognee** $7.5M seed (фев 2026, open-source memory layer) · **Mem0** $24M, 48k звёзд · **Letta** $10M · **Zep**.
- Инкумбенты той же формы: Dust, Atlassian Rovo, SharePoint agents + Copilot Studio, Notion agents, Slite Agent (июнь 2026, «самообновляющаяся база»).
- Никто масштабно не продаёт именно «Obsidian-вольт + флот Claude-машин на всю компанию». Дыра есть, но дыра ≠ спрос — проверяется только платными пилотами.

## Консалтинг и цена компаний

- AI-консалтинг рынок: ~$22B (2025, оценка одной конторы, directional). KM-консалтинг отдельно никто не считает — растворён в «AI enablement».
- Чеки: SMB $5–25k сетапы · mid-market $25–200k стратегия / $75–500k внедрение · Big4 $500k–$1M стратегия, $3–10M+ внедрение.
- **Стоимость самих контор:** чистый консалтинг = 1–2× прибыли (не выручки!); AI-бутики 3–12× EBITDA (retainer-heavy дороже); SaaS = 8–20× ARR. Разница в 10× — главный аргумент продуктизировать, а не консультировать. Roll-up AI-агентств реален как скупка по 0.7–1.0× выручки, как «волна дорогих сделок» — [speculative].
- Методологии: KCS (саппорт) — единственная взрослая и растущая с AI; BASB корпоративно = $2.15M выручки ВСЕЙ Forte Labs за 2025 — микрорынок; ISO 30401 — спящая ниша.

## Расхождения рельс (сохранены)

- **Кому продавать первым:** chatgpt — mid-market professional services («Delivery Memory Pilot», аудит €7.5–15k → пилот €25–60k); grok — AI-native фирмы 10–80 человек, которые уже живут в markdown; claudeai — mid-market 100–500 сотр. с уже задеплоенными агентами, $500–2k/мес за компанию (не за место). Пересечение: knowledge-heavy фирма 20–200 человек, вход через консалтинг-пилот.
- **Grok жёстче всех про имя:** «second brain» в счёте корпорату = яд; и даёт дешёвый решающий тест (90 дней): 20 фирм 15–80 чел., питч из 3 предложений без слов «второй мозг», платный 30-дневный пилот. <3 пилотов = возражение операционно верно для нас; ≥3 = прав Антон.
- **claudeai единственный с живым вебом** — его 2026-цифры (Interloom, Cognee, Capacity/Starmind, Glean $768M раунд авг 2026, Meta купила Limitless дек 2025) самые свежие.

## Что это меняет для нас

1. Возражение собеседника принять НАРОВНЕ как урок про слово, отвергнуть как приговор рынку. Не «корпоратам не нужно», а «нет строки бюджета с таким названием и нет CKO, который подпишет».
2. Продавать словами покупателя: «organizational memory for your agent fleet» / «agent grounding layer» — дверь CTO/Head of AI (владелец бюджета есть), не «knowledge management» (владельца нет).
3. Согласуется с мемо HUB-03 и HUB-01: горизонтальный «второй мозг каждому SMB» не запускать; агентная дверь — единственная, что открывается.
4. Рекомендация (пересечение трёх рельс, confidence [emerging]): 2–3 платных консалтинг-пилота $15–40k на knowledge-heavy фирмах 20–200 чел. как paid discovery → продуктизация «managed agent memory layer» для mid-market. Главное допущение: mid-market заплатит $1–5k/мес; проверка = grok-тест 90 дней.
